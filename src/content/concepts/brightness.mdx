A digital photo is a grid of tiny squares called pixels: here 300 rows by 480 columns, 144,000 pixels. Each pixel stores three numbers (red, green, blue), each from 0 (none) to 255 (full)<Cite c="Gonzalez & Woods, 2018" />. To print in three colours we need one number that says how dark a pixel is. We use the average of the three: the brightness, from 0 (black) to 255 (white). The code calls it `light`.
