Two thresholds cut the brightness scale into three bands: below 90 blue ink, below 150 pink, the rest paper. In the rule each band is an `if` with a `return`. A `return` ends the rule for that pixel, so the lines below it never run. A screen print works in bands too: one stencil per ink, each printed flat<Cite c="Kipphan, 2001" />.
