A threshold is one number on the brightness scale. The rule asks every pixel one yes/no question, `light < THRESHOLD`. True gets ink, False stays paper. The grid of answers is a mask: it marks where the ink goes. This is thresholding, a way to split a picture in two<Cite c="Gonzalez & Woods, 2018" />. Raise the threshold and more pixels fall below it.
