A threshold is one number on the brightness scale. The rule asks every pixel one yes/no question, `light < THRESHOLD`. True gets ink, False stays paper. The grid of True/False answers is called a mask: it shows where the ink goes. Splitting a picture in two like this is called thresholding<Cite c="Gonzalez & Woods, 2018" />. Raise the threshold and more pixels fall below it.
