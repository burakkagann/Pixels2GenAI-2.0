## Overview <a id="overview"></a>

Ernst Chladni's 1787 *Discoveries in the Theory of Sound* documented one of the most beautiful demonstrations in classical physics: spread sand on a metal plate, bow it with a violin, and the sand collects along the **nodal lines** — the curves where the plate doesn't vibrate. Different bowing positions excite different vibration modes, and each mode has its own characteristic sand pattern of symmetric curves [1]. The mathematics is one Hamilton-like equation of two integer mode numbers `(m, n)`. **Cymatics** is the modern term for these visualisations, popularised by Hans Jenny's 1967 book of the same name [2]. This lesson generates Chladni figures from the equation, no plate required.

### Learning objectives

<ol class="obj-list">
  <li>State the Chladni nodal equation `cos(mπx) cos(nπy) − cos(nπx) cos(mπy) = 0` and how mode numbers control the figure.</li>
  <li>Render the nodal lines as a thin mask: `|z| < ε` for small ε.</li>
  <li>Identify the symmetry classes — `(m, n)` and `(n, m)` give rotated versions of the same figure.</li>
  <li>Build a grid of multiple mode pairs to compare patterns.</li>
</ol>

## Quick start — the `(4, 6)` Chladni mode <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image

H, W = 400, 400
m, n = 4, 6

y, x = np.indices((H, W)).astype(np.float64)
xn = x / W * np.pi
yn = y / H * np.pi

# Chladni nodal expression
z = np.cos(m * xn) * np.cos(n * yn) - np.cos(n * xn) * np.cos(m * yn)

# Sand collects where the plate doesn't move (|z| near 0)
sand = (np.abs(z) < 0.06).astype(np.float64)

Image.fromarray((sand * 255).astype(np.uint8), 'L').save('chladni_46.png')
```
</CodeBlock>

<Admonition type="tip">
The threshold `|z| < 0.06` is what gives the lines a visible thickness. A smaller threshold gives thinner lines; a larger one gives wider bands. Real sand piles up in finite-width bands too, so the threshold reflects how big the sand grains are.

## Core concepts <a id="core-concepts"></a>

### Concept 1 — The Chladni nodal equation

For a thin square plate with free edges, the vibration modes are products of cosines:

```
mode_mn(x, y) = cos(mπx) cos(nπy)
```

where `(m, n)` are integer mode numbers and `x, y ∈ [0, 1]` are normalised plate coordinates. Each pair `(m, n)` gives a distinct vibration pattern with `(m + 1)(n + 1)` antinodes.

But pure `(m, n)` modes give simple grid-like patterns. The *interesting* Chladni figures come from the **superposition** of `(m, n)` and `(n, m)` modes:

```python
z = np.cos(m * π * x) * np.cos(n * π * y) - np.cos(n * π * x) * np.cos(m * π * y)
```

The minus sign is what produces the diagonal patterns. The nodal lines (where the plate doesn't move) live where `z = 0` — and that is where sand collects [3].

### Concept 2 — Render nodal lines as thin masks

Programmatically extracting "where z = 0 exactly" is impossible — a continuous function rarely hits exactly zero at the pixel grid. The standard workaround is a *small-magnitude* mask:

```python
sand = np.abs(z) < ε       # ε controls line thickness
```

The mask is `True` for pixels close to the nodal curve and `False` elsewhere. Tuning `ε`:

- `ε = 0.02` — very thin lines, suitable for high-resolution figures.
- `ε = 0.06` — 1–2 pixel-wide lines at 400×400. Good default.
- `ε = 0.15` — wide bands; reads as "the area where sand collects" rather than the curve itself.

For more rigorous nodal extraction, you would use *marching squares* (3.4.3 footnote) to trace the zero contour exactly. The mask threshold is the cheap version.

### Concept 3 — Mode pairs and symmetry

The pattern from `(m, n)` and the pattern from `(n, m)` are *rotated versions of each other* — same set of curves, rotated 90°. The pattern from `(m, n)` has different complexity than from `(m', n')` when the *parities* of m, n differ:

| Mode (m, n) | Pattern character |
|-------------|-------------------|
| (1, 2)      | Simple cross |
| (2, 3)      | Three-fold lobes |
| (3, 5)      | Hexagonal symmetry |
| (4, 6)      | Octagonal symmetry |
| (5, 7)      | Twelvefold pattern |

The number of nodal intersections scales as `m × n`. Higher modes have richer geometry; the eye reads them as more "complex" Chladni figures [4].

<Admonition type="dyk" title="Technical note · the actual physics">
The Chladni equation here treats the plate as a simply-supported square, which gives the cleanest patterns. Real plates have *clamped* edges (or free, depending on the experiment), which changes the boundary conditions and the resulting modes. The Bessel-function modes for circular plates are even more spectacular but harder to compute by hand. Ernst Chladni's original observations were of square and circular plates excited by a violin bow, and the figures matched the simply-supported approximation surprisingly well [1, 5].
</Admonition>

## Exercises <a id="exercises"></a>

Three exercises in **Execute → Modify → Create** order: render `(4, 6)`, sweep mode pairs, then animate.

<Exercise n={1} kicker="EXECUTE" title="Render the `(4, 6)` figure">

Run `chladni.py` from the quick start.

**Reflection questions**

- The pattern has 4-fold symmetry but you used `(4, 6)` modes. Why?
- What happens if you swap to `(6, 4)`?
- What does the figure look like for `(m, n) = (1, 1)`?

<Dropdown summary="Answers">

**4-fold symmetry** — the symmetry of a Chladni figure comes from the difference `cos(mπx)cos(nπy) − cos(nπx)cos(mπy)`, which has the property `f(x, y) = -f(y, x)` (the figure is anti-symmetric under x↔y swap). For `(m=4, n=6)`, the 4× factor in cos(mπx) creates 4 high-frequency peaks along x, and similarly 6 along y, giving the visible 8-pointed star symmetry.

**Swap (6, 4)** — same pattern but rotated 90°. The equation is anti-symmetric under x↔y, so swapping m and n flips the figure.

**(1, 1)** — `cos(πx)cos(πy) − cos(πx)cos(πy) = 0` identically. No nodal pattern — every pixel is "sand." A degenerate mode.

</Dropdown>

</Exercise>

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image

H, W = 300, 300
y, x = np.indices((H, W)).astype(np.float64)
xn = x / W * np.pi
yn = y / H * np.pi

frames = []
for i in range(12):
    m = 2 + i * 0.3
    n = 3.5 + i * 0.4
    z = np.cos(m * xn) * np.cos(n * yn) - np.cos(n * xn) * np.cos(m * yn)
    sand = (np.abs(z) < 0.06).astype(np.float64)
    img = (sand * 255).astype(np.uint8)
    Image.fromarray(img, 'L').save(f'chladni_frame_{i:02d}.png')
    frames.append(img)

try:
    import imageio
    imageio.mimsave('chladni_sweep.gif', frames, fps=4)
except ImportError:
    pass
```
</CodeBlock>

**How it works:**

- Fractional mode numbers are physically *unphysical* — a real plate only vibrates at discrete eigenfrequencies. But the equation still produces a continuous family of patterns that smoothly interpolates between integer-mode figures.
- The 12-frame sweep shows the patterns morphing from one integer mode to the next.
- The optional `imageio.mimsave` assembles a GIF; without it, the PNG sequence works fine for sharing as a slideshow.

</Dropdown>

#### Make it your own

- Try the *plus* sign instead of *minus* in the Chladni equation — `cos(mπx)cos(nπy) + cos(nπx)cos(mπy)`. The resulting figures are different (more "filled" patterns).
- Add a third dimension: `f(x, y, z) = cos(mπx)cos(nπy)cos(pπz)` for 3D vibration modes. Render a slice through z = constant; the patterns shift as z varies.

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Chladni figures are the nodal patterns of a vibrating plate — the curves along which the plate doesn't move, where sand collects when the plate is excited. The mathematics: `z(x, y) = cos(mπx) cos(nπy) − cos(nπx) cos(mπy)`, with `(m, n)` integer mode numbers. Render the nodal lines as a thin mask `|z| < ε` where ε is small. Each mode pair `(m, n)` gives a distinct symmetric figure; swap-symmetric pairs `(m, n)` and `(n, m)` are rotated versions of each other. The 18th-century Chladni and the 20th-century Jenny used these patterns to visualise sound; we use them today as procedural art and as a reminder that physics has been generating beautiful symmetric structure for centuries before we had the computers to plot it.

</Admonition>

**Common pitfalls to avoid**

- Setting `(m, n) = (m, m)` — gives an identically-zero field. Pick distinct mode numbers.
- Threshold ε too small — nodal lines are too thin to see at low resolution.
- Threshold ε too large — the bands grow until they touch and the figure looks like a chequerboard.
- Forgetting the π in the cosines — the period is wrong, the figure looks scaled.
- Comparing to interference (6.4.2) — both use cosines but Chladni's modes are *eigenmodes* of a bounded plate; interference is a *travelling-wave* sum.
