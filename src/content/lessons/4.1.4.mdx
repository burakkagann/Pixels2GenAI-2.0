## Overview <a id="overview"></a>

A **Julia set** is what you get when you run the Mandelbrot iteration with the roles of $c$ and $z$ swapped. In Mandelbrot, $z_0 = 0$ is fixed and you sweep $c$ across the complex plane. In Julia, **$c$ is fixed** and you sweep $z_0$ across the plane instead. Every choice of $c$ gives a different Julia set, and the resulting fractal lives entirely inside the disc $|z| \le 2$. Gaston Julia and Pierre Fatou described these sets in 1918, decades before any computer could draw one [1].

The deep connection: the **Mandelbrot set is the map of which Julia sets are connected**. Pick a $c$ inside the Mandelbrot set and the corresponding Julia set is a single connected blob with intricate boundary detail. Pick a $c$ outside it and the Julia set fractures into "Fatou dust" — a Cantor-like cloud of disconnected points [2]. That correspondence is what makes Julia sets feel like a sibling exercise to 4.1.3 rather than a brand-new algorithm.

## Quick start — a classic dendrite <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image

SIZE, MAX_ITER = 600, 200
C = complex(-0.7, 0.27015)            # the parameter is now fixed

# Every pixel is its own starting z_0 (no z_0 = 0 here)
x = np.linspace(-1.6, 1.6, SIZE)
y = np.linspace(-1.6, 1.6, SIZE)
real, imag = np.meshgrid(x, y)
z = real + 1j * imag

iterations = np.zeros(z.shape, dtype=np.int32)
for _ in range(MAX_ITER):
    bounded = np.abs(z) <= 2
    z[bounded] = z[bounded]**2 + C    # C is a scalar — broadcasts
    iterations[bounded] += 1

out = np.zeros((SIZE, SIZE), dtype=np.uint8)
outside = iterations < MAX_ITER
out[outside] = (iterations[outside] / MAX_ITER * 255).astype(np.uint8)
Image.fromarray(out, mode='L').save('simple_julia.png')
```
</CodeBlock>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Mandelbrot vs. Julia: swap the variable

The Mandelbrot iteration runs "next $z$ = current $z$ squared plus $c$" with two pieces of state per pixel: $z$, which evolves, and $c$, which stays constant for that pixel. In **Mandelbrot**, every pixel has a different $c$ and they all start from the same $z_0 = 0$. In **Julia**, every pixel starts from a different $z_0$ and they all use the same $c$.

That single swap changes everything. The Mandelbrot set is a **parameter-space picture**: each pixel asks "how does the system behave for this value of the parameter $c$?" The Julia set is a **phase-space picture**: each pixel asks "how does the orbit behave starting from this initial condition $z_0$?" Both diagrams come from the same quadratic map, and both use the same $|z| > 2$ escape test [3].

<CodeBlock lang="python" file="side_by_side.py">
```python
# Mandelbrot core: z varies, c is the grid
z = np.zeros_like(c)
for _ in range(N):
    bounded = np.abs(z) <= 2
    z[bounded] = z[bounded]**2 + c[bounded]    # c is an array

# Julia core: z is the grid, c is fixed
z = real + 1j * imag                            # z grid
for _ in range(N):
    bounded = np.abs(z) <= 2
    z[bounded] = z[bounded]**2 + C              # C is a scalar — broadcasts
```
</CodeBlock>

The code is almost identical; the meaning is completely different.

<Admonition type="dyk" title="Did you know · Julia sets before computers">
Gaston Julia published *Mémoire sur l'itération des fonctions rationnelles* in 1918 — a 199-page monograph fully characterising what we now call Julia sets, but with no computer to render them. He worked entirely with hand-drawn diagrams and symbolic analysis [1]. The pictures we take for granted today did not exist until Mandelbrot rendered them at IBM in the late 1970s.
</Admonition>

### Concept 2 — The Mandelbrot/Julia correspondence

There is a precise theorem that links the two sets:

> **A Julia set is connected if and only if the corresponding $c$ lies inside the Mandelbrot set.**

The Mandelbrot set is the **connectivity locus** of the Julia family [2]. Pick a $c$ deep inside the cardioid and the Julia set is a connected blob with a smooth-ish boundary. Pick a $c$ along the boundary of the Mandelbrot set and the Julia set is intricate, dendritic, fractal in every direction. Pick a $c$ outside the Mandelbrot set and the Julia set explodes into "Fatou dust" — a Cantor cloud of disconnected points with no interior at all.

### Concept 3 — Rainbow colouring with phase-shifted sines

The two examples so far use a grayscale ramp — simple, but visually flat. A **phase-shifted sine palette** turns the same iteration data into a vivid cyclic rainbow:

<CodeBlock lang="python" file="palette.py">
```python
norm = iterations / MAX_ITER
outside = iterations < MAX_ITER

image[outside, 0] = (128 + 127*np.sin(norm[outside]*freq + 0)).astype(np.uint8)
image[outside, 1] = (128 + 127*np.sin(norm[outside]*freq + 2)).astype(np.uint8)
image[outside, 2] = (128 + 127*np.sin(norm[outside]*freq + 4)).astype(np.uint8)
```
</CodeBlock>

Three sines at the same frequency, offset by 0, 2, 4 radians. The offsets are roughly 120° apart — close enough to a colour-wheel triplet to produce a rainbow without explicitly converting through HSV. `freq` controls how many cycles fit across the escape ramp; higher `freq` produces tighter colour bands.

The colour palette is decoupled from the maths. The iteration count array `iterations` is the **physical** content; any choice of colour mapping is a presentation layer. Swap the palette without rerunning the iteration loop.
</Admonition>

**Reflection questions**

- Compare this lesson's quick-start to the Mandelbrot quick-start in 4.1.3. Which two lines changed?
- The Julia set is symmetric. Across which point? Why?
- The viewport is `[-1.6, 1.6]` on both axes. Why does the renderer not need to look outside the disc of radius 2?

<Dropdown summary="Answers">

**The two changed lines** — (a) `z = real + 1j * imag` instead of `z = np.zeros_like(c)`, and (b) `z**2 + C` (scalar) instead of `z**2 + c` (array). Everything else is identical.

**Symmetry around the origin** — the map $z \to z^2 + c$ has the property that $z$ and $-z$ produce the same orbit after the first step (because $(-z)^2 = z^2$). So if $z_0$ is in the Julia set, so is $-z_0$. That gives the set a 180° rotational symmetry around 0.

**Disc of radius 2** — the escape theorem says any orbit that crosses $|z| > 2$ escapes to infinity. So no point with $|z_0| > 2$ can be in the Julia set: it would escape on the first step. Sampling outside that disc just wastes pixels on confirmed escapees.

</Dropdown>

</Exercise>

<Exercise n={2} kicker="MODIFY" title="Sweep the parameter family">

Modify `simple_julia.py` to render Julia sets at four different $c$ values and compare them. Stick with grayscale for fair comparison.

**Goals**

1. **Connected rabbit.** Use $c = -0.4 + 0.6i$. The expected shape resembles a rabbit, hence its name in fractal geometry literature.
2. **San Marco lagoon.** Use $c = -0.75 + 0i$. This $c$ sits on the real axis at the cusp of the main cardioid; the Julia set has a distinctive double-lobed silhouette.
3. **Fatou dust.** Use $c = 0.4 + 0.4i$ — well outside the Mandelbrot set. The Julia set should fragment into a sparse cloud of disconnected points.
4. **Spiral siege.** Use $c = -0.835 - 0.2321i$ and bump `MAX_ITER` to 400. The shape should fill with tightly wound spirals.

<Dropdown summary="Goal 1 — what to expect">

A connected blob with two large oval "ears" sticking out and a long curved tail. The rabbit is a poster child of the Julia family because its silhouette is unmistakable. This $c$ sits inside the period-3 bulb of the Mandelbrot set.

</Dropdown>

<Dropdown summary="Goal 2 — what to expect">

A horizontal figure-eight-ish silhouette with deep cusps. This $c$ is exactly at the boundary between two Mandelbrot bulbs, so the Julia set has a particularly delicate boundary structure. The dynamics here are formally "parabolic" — the orbit slowly spirals toward a fixed point [2].

</Dropdown>

<Dropdown summary="Goal 3 — what to expect">

Sparse dust — no connected region anywhere. The Mandelbrot/Julia correspondence in action: $c = 0.4 + 0.4i$ has $|c| > 0.5$ and you can verify it is outside the Mandelbrot set by running one Mandelbrot iteration on it (it escapes quickly). The corresponding Julia set is totally disconnected.

</Dropdown>

<Dropdown summary="Goal 4 — what to expect">

A spiral siege. At 200 iterations the boundary looks unresolved; at 400 you see swirling arms that wind tightly around two centres. This $c$ requires more iterations because the orbits spend a long time near the boundary before deciding to escape.

</Dropdown>

</Exercise>

```python
import numpy as np
from PIL import Image

def rainbow_palette(iterations, max_iter, freq=8.0):
    size = iterations.shape[0]
    image = np.zeros((size, size, 3), dtype=np.uint8)
    norm = iterations / max_iter
    outside = iterations < max_iter
    image[outside, 0] = (128 + 127 * np.sin(norm[outside] * freq + 0)).astype(np.uint8)
    image[outside, 1] = (128 + 127 * np.sin(norm[outside] * freq + 2)).astype(np.uint8)
    image[outside, 2] = (128 + 127 * np.sin(norm[outside] * freq + 4)).astype(np.uint8)
    return image
```

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

A Julia set fixes $c$ and sweeps $z_0$ across the complex plane — the inverse setup of the Mandelbrot iteration. Each $c$ gives a different Julia set. Connected Julia sets correspond to $c$ values **inside** the Mandelbrot set; disconnected "dust" sets correspond to $c$ outside. The rendering code is almost the same as Mandelbrot — `z` is the grid, `c` is a scalar — and the same escape-time threshold $|z| > 2$ applies. Phase-shifted sine palettes decouple the visual presentation from the underlying iteration counts, letting you recolour without recomputing. The Mandelbrot/Julia duality is the cleanest example of the **parameter space vs. phase space** distinction in dynamical systems — and Julia sets set up the broader theme of **iterated function systems** that returns in 4.1.5 (Sierpinski) and 4.3 (L-systems).

</Admonition>

**Common pitfalls to avoid**

- **Initialising `z = np.zeros_like(c)`.** That is the Mandelbrot setup. Julia sets start with `z` *as* the grid; there is no separate `c` array to copy from.
- **Using an array for `c`.** `c` must be a scalar in this lesson. If you accidentally make it a grid you get the Mandelbrot set instead.
- **Forgetting to clip the viewport.** Pixels outside $|z| = 2$ escape on iteration 1 — they show no detail and waste compute. Keep the `linspace` bounds inside `[-2, 2]`.
- **Underiterating near the Mandelbrot boundary.** Julia sets for $c$ near the Mandelbrot boundary need 400+ iterations to look right. Inside the bulbs, 100 is usually enough.
