## Overview <a id="overview"></a>

In 1904, Helge von Koch designed a curve that was meant to illustrate a paradox in real analysis: a closed curve that has *finite area* enclosed but *infinite perimeter* [1]. The construction is short. Start with an equilateral triangle. Replace each side's middle third with two sides of a smaller equilateral triangle pointing outward. Each replacement adds four segments where there was one, multiplies the perimeter by $4/3$, and adds area $\propto (1/3)^k$ at iteration $k$. The geometric series for the area converges, the geometric series for the perimeter does not. After infinitely many iterations the curve has $\infty$ length and area $8/5$ of the original triangle.

This was the first widely-known fractal — Mandelbrot called the Koch snowflake "the introduction" to fractal geometry [2] — and it is the cleanest demonstration that the L-system framework from 4.3.1 can produce **geometric** rather than **organic** fractals just by swapping rules. The drawing machinery doesn't change. Same axiom-and-rules rewriting, same turtle interpreter — different axiom, different rule, snowflake instead of fern.

## Quick start — the snowflake <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import math
from PIL import Image, ImageDraw

AXIOM = "F++F++F"        # equilateral triangle (three F's + 120° turns)
RULES = {"F": "F-F++F-F"} # replace each F with the bump pattern
ITERATIONS = 4
ANGLE = 60

# Apply rules
s = AXIOM
for _ in range(ITERATIONS):
    s = "".join(RULES.get(c, c) for c in s)

# Turtle interpretation — step shrinks by 3 each iteration so the snowflake fits
step = 400 / (3 ** ITERATIONS)
img = Image.new("RGB", (700, 600), (12, 14, 28))
draw = ImageDraw.Draw(img)
x, y, angle = 150, 200, 0

for c in s:
    if c == "F":
        nx = x + step * math.cos(angle)
        ny = y + step * math.sin(angle)
        draw.line([(x, y), (nx, ny)], fill=(220, 240, 255), width=2)
        x, y = nx, ny
    elif c == "+": angle -= math.radians(ANGLE)
    elif c == "-": angle += math.radians(ANGLE)

img.save("simple_koch.png")
```
</CodeBlock>

The axiom `F++F++F` is an equilateral triangle: three forward segments separated by **two** `+` turns (each `+` is 60°, so two of them is the 120° external angle of an equilateral triangle). Change the axiom to `F+F+F+F` with `+` = 90° and you get a square — same machinery, square boundary.

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Axiom and rule for a closed curve

For an L-system to produce a **closed** curve, the axiom has to make a full loop with the turtle returning to its starting position and orientation. The classic Koch axiom is the equilateral triangle:

> **Axiom:** `F++F++F`.

Three forward segments, two turns of $2 \times 60° = 120°$ between them, the third edge brings the turtle back to the start. The turtle's net rotation is $3 \times 120° = 360°$ — a full loop, so the orientation is also restored.

The rule that adds the snowflake bumps replaces each `F` with a longer string of segments and turns:

> **Rule:** `F` → `F-F++F-F`.

Read this as: "go forward, turn right 60° (`-`), go forward, turn left 120° (`++`), go forward, turn right 60° (`-`), go forward." The result is a `_/\_` bump that replaces the original straight segment. The bump has the same start and end, but a new outward triangle.

<Admonition type="dyk" title="Did you know · infinite length, finite area">
Each iteration multiplies the curve's perimeter by 4/3 (each edge becomes 4 edges of length 1/3). After $n$ iterations the perimeter is $3 \cdot (4/3)^n$, which goes to infinity as $n \to \infty$. But the area added at each iteration is bounded — the new triangles get small fast. Summing the geometric series gives a finite limit: the Koch snowflake encloses an area of exactly $2\sqrt 3 / 5$ for a unit-side initial triangle, while its boundary is infinitely long [1]. Helge von Koch built it to argue that "natural" boundaries can have this paradoxical character, and Mandelbrot built fractal geometry on top of that idea.
</Admonition>

### Concept 2 — Iteration, fractal dimension, and the step-size halving rule

The Koch snowflake's fractal dimension is

> $D = \log 4 / \log 3 \approx 1.262$.

The reasoning: at each iteration, one segment of length $L$ becomes 4 segments of length $L/3$. The number of self-similar copies is 4; the scale factor is $1/3$; the dimension equals the log of copy-count divided by the log of inverse-scale, which is $\log 4 / \log 3$ [3]. A line has dimension 1, a filled triangle has dimension 2, and the Koch boundary sits in between — strictly more than a line, strictly less than a filled area.

To render the snowflake at every iteration with the **same** overall size, the turtle's step size must shrink by exactly the same factor: step divided by 3 per iteration. That is why the quick start uses `step = 400 / (3 ** ITERATIONS)` rather than a fixed step. Forget this and each iteration draws a snowflake 3× the size of the previous, quickly running off the canvas.

### Concept 3 — Rule variants generate the whole geometric family

The Koch snowflake is one rule in a small family of geometric replacement fractals. Changing the rule produces a different curve:

| Variant | Axiom | Rule | Angle | Shape |
|---------|-------|------|-------|-------|
| Snowflake | `F++F++F` | `F → F-F++F-F` | 60° | the classic, bumps point outward |
| Anti-snowflake | `F++F++F` | `F → F+F--F+F` | 60° | bumps point **inward** — same idea, inverted turn |
| Quadratic Koch | `F+F+F+F` | `F → F+F-F-F+F` | 90° | square-symmetric variant |
| Sierpinski arrowhead | `A` | `A → B-A-B`, `B → A+B+A` | 60° | the Sierpinski gasket, drawn as an L-system curve |

**Reflection questions**

- How long is the instruction string at iteration $n$?
- The starting triangle has perimeter $3L$. What is the perimeter at iteration $n$ in terms of $L$? Verify your formula matches Concept 2's growth-by-$4/3$ claim.
- Visually compare iterations 3 and 4. Where does the new detail appear? Could you tell them apart at a distance of 2 metres from the screen?

<Dropdown summary="Answers">

**Instruction-string length** — the axiom has 7 characters. Each iteration replaces every `F` (initially 3) with 7 characters. After $n$ iterations the count of `F`s is $3 \cdot 4^n$ (each `F` becomes 4 new `F`s) and the total string length is $3 \cdot 4^n + 2 \cdot (4^n - 1) / 3 \cdot 2 + \ldots$ — too messy to compute in closed form by hand, but at iteration 4 it is 1,792 (matching the script's printout).

**Perimeter** — each iteration replaces every segment of length $L_n$ with 4 segments of length $L_n / 3$, so the per-segment length is $L_n = L / 3^n$. The number of segments is $3 \cdot 4^n$ (start with 3 sides, multiply by 4 each iteration). Perimeter = $3 \cdot 4^n \cdot L / 3^n = 3L \cdot (4/3)^n$ — diverges as $n \to \infty$.

**Iterations 3 vs 4** — at 2 metres, indistinguishable. The boundary detail at iteration 4 is sub-pixel for most screens. The visual content of the snowflake saturates around iteration 3–4, which is why we don't bother rendering it at iteration 10.

</Dropdown>

</Exercise>

<Exercise n={3} kicker="CREATE" title="Design two variants">

Write the L-system rules for two more variants, then render them on the same framework.

**Goals**

1. **Anti-snowflake.** Same axiom and angle as the standard snowflake, but reverse the turn directions so the bumps point **inward** instead of outward. Hint: replace `-` with `+` and vice versa in the rule.
2. **Quadratic Koch.** A square-symmetric variant with axiom `F+F+F+F` (a square), `ANGLE = 90`, and rule `F → F+F-F-F+F`. Each side gets a square notch instead of a triangular bump.

<CodeBlock lang="python" file="exercise3_starter.py">
```python
import math
from PIL import Image, ImageDraw

def turtle_draw(axiom, rules, iterations, angle_deg, step, start, start_angle,
                size, color):
    s = axiom
    for _ in range(iterations):
        s = "".join(rules.get(c, c) for c in s)

    img = Image.new("RGB", size, (12, 14, 28))
    draw = ImageDraw.Draw(img)
    x, y = start
    angle = start_angle
    for c in s:
        if c == "F":
            nx = x + step * math.cos(angle)
            ny = y + step * math.sin(angle)
            draw.line([(x, y), (nx, ny)], fill=color, width=2)
            x, y = nx, ny
        elif c == "+": angle -= math.radians(angle_deg)
        elif c == "-": angle += math.radians(angle_deg)
    return img

# TODO 1: Anti-snowflake
anti_img = turtle_draw(
    axiom="F++F++F",
    rules={"F": "..."},   # flip the turn directions in the snowflake rule
    iterations=4,
    angle_deg=60,
    step=240 / 3**4,
    start=(100, 200), start_angle=0,
    size=(600, 500), color=(255, 200, 110),
)

# TODO 2: Quadratic Koch (square axiom + 90° turns)
quad_img = turtle_draw(
    axiom="F+F+F+F",
    rules={"F": "..."},   # quadratic-Koch rule
    iterations=3,
    angle_deg=90,
    step=200 / 3**3,
    start=(150, 100), start_angle=0,
    size=(600, 500), color=(160, 220, 255),
)
```

#### Make it your own

- **Koch antibody.** Iterate from a single straight line instead of a triangle (`axiom = "F"`). You get the Koch curve, not the snowflake — an open curve that crosses itself zero times and still has infinite length on the unit interval.
- **3D Koch.** Generalise to 3D with a turtle that has heading + pitch + roll. The Koch surface is a 3D analogue with similar paradoxical properties; the L-system needs roll-axis turns to describe it.
- **Snowflake fonts.** Embed text in the centre of each snowflake by drawing the L-system around a pre-existing glyph. Used as a custom "fractal-ornament" character set in laser-cutting tools.

</Exercise>

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

The Koch snowflake is the L-system framework from 4.3.1 applied to a closed-curve geometry: axiom `F++F++F` (equilateral triangle), rule `F → F-F++F-F` (bump replacement), turn angle 60°. Each iteration multiplies the perimeter by $4/3$ and shrinks each segment by 3 — the fractal dimension is $\log 4 / \log 3 \approx 1.262$. To keep the overall size constant across iterations, the turtle step must shrink by 3 each pass. The same machinery generates an entire family: anti-snowflake (turn-flipped), quadratic Koch (90°-symmetric), Sierpinski arrowhead (two-symbol production). The framework is universal; the rule decides everything. Together with 4.3.1 and 4.3.3 (Penrose tiling), this completes the L-systems triad — organic, geometric, and aperiodic, all from the same string-rewriting paradigm.

</Admonition>

**Common pitfalls to avoid**

- **Wrong axiom topology.** `F++F+F` (with a single `+` between two `F`s) is not a triangle — the turtle doesn't close the loop. Always check that the axiom's total turn equals 360° and edge count matches.
- **Forgetting to shrink the step.** Iteration $n$ needs step $= L_0 / 3^n$ to stay at constant size. Otherwise the snowflake grows by factor 3 every iteration.
- **Open instead of closed curve.** `axiom = "F"` with the snowflake rule gives the Koch *curve*, not the snowflake. The triangle axiom is what makes the boundary closed.
- **Mixing the two turn conventions.** Different references use `+` for "turn left" or "turn right" — be consistent within a single rule set. The convention used here: `+` decreases angle (turn left in standard math orientation), `-` increases it.
