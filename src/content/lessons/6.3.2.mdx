## Overview <a id="overview"></a>

Real cumulus clouds have a curious property: most of the sky is empty, but the cloud regions are *bright white with a flat bottom*. The procedural recipe captures this in two lines. Take an fbm field; threshold below `t` for "no cloud," and apply linear amplification above `t` for "cloud body":

```
cloud = clip((z − t) × gain, 0, 1)
```

The thresholding is what creates the discrete cloud edges; the gain is what flattens the cloud body to near-white. Composite over a sky gradient and you have a credible cumulus sky [1]. The same trick generalises to smoke, fog, and any volumetric look where "most of the field is empty, the rest is a soft glow."

### Learning objectives

<ol class="obj-list">
  <li>Build a vertical sky gradient by linear interpolation between two RGB stop colours.</li>
  <li>Threshold an fbm field with `clip((z − t) * gain, 0, 1)` and read it as a continuous cloud-density mask.</li>
  <li>Alpha-composite the cloud mask over the sky to get the final image.</li>
  <li>Tune `t` (cloud coverage) and `gain` (cloud sharpness) for different cloud types.</li>
</ol>

## Quick start — clouds over sky <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image
# fbm() from 6.1.1 in scope

H, W = 300, 600

# Vertical sky gradient: deep blue at top, paler near horizon
sky_top = np.array([0.40, 0.60, 0.90])
sky_bot = np.array([0.85, 0.92, 1.00])
yy = np.linspace(0, 1, H)[:, None, None]
sky = sky_top * (1 - yy) + sky_bot * yy
sky = np.broadcast_to(sky, (H, W, 3)).copy()

# fbm cloud density, thresholded and amplified
cloud = fbm((H, W), scale=80, octaves=5, seed=7 + 90)
cloud = np.clip((cloud - 0.45) * 4, 0, 1)            # threshold + gain

# Composite: white cloud over sky
cloud_rgb = np.stack([cloud, cloud, cloud], axis=-1)
sky = sky * (1 - cloud_rgb) + cloud_rgb * 1.0

Image.fromarray((np.clip(sky, 0, 1) * 255).astype(np.uint8)).save('clouds_over_sky.png')
```
</CodeBlock>

The cloud body is *not* a soft Perlin blob — it is a *binary-like* mask with soft edges. The `clip((z − t) * gain, 0, 1)` line is what creates the cloud silhouette; the gain controls how sharp the boundary is.

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Vertical sky gradient

A clear sky transitions from deep saturated blue at the zenith to paler near-white blue at the horizon. The simplest credible sky is a vertical lerp between two stops:

```python
sky_top = np.array([0.40, 0.60, 0.90])      # zenith
sky_bot = np.array([0.85, 0.92, 1.00])      # horizon
yy = np.linspace(0, 1, H)[:, None, None]    # 0 at top, 1 at bottom
sky = sky_top * (1 - yy) + sky_bot * yy
```

The lerp is the same construction from 2.2.1 (gradients), now applied to a colour pair. Broadcasting handles the per-column extension automatically.

For sunsets, swap `sky_top` to deep purple and `sky_bot` to vivid orange. For storms, both stops go grey. The composition trick is the same — only the colours change [2].

### Concept 2 — Threshold + gain = cloud mask

Plain fbm gives a smooth field in `[0, 1]` with detail at all scales. Real clouds are *not* smooth — they have crisp boundaries between "cloud" and "empty sky." The two-parameter conversion:

```python
cloud = np.clip((z - t) * gain, 0, 1)
```

- `(z - t)` shifts the field so anything below `t` becomes negative.
- `* gain` amplifies the values that survive — a small positive remainder gets pushed close to 1, the negatives stay negative.
- `np.clip(..., 0, 1)` clamps the output to a valid `[0, 1]` mask.

`t = 0.45` means roughly the top half of the fbm field becomes cloud. `gain = 4` means anything 0.25 above threshold reaches full intensity. The combination gives a hard cloud edge with a small soft-shoulder region [3].

| t   | gain | Look |
|-----|------|------|
| 0.6 | 8    | Sparse, sharp clouds |
| 0.45| 4    | Standard cumulus (quick start) |
| 0.3 | 2    | Overcast, soft edges |
| 0.2 | 1    | Light fog everywhere |

### Concept 3 — Alpha compositing the cloud over the sky

With the cloud mask in `[0, 1]`, the composite is one line:

```python
out = sky * (1 - cloud_rgb) + cloud_rgb * cloud_color
```

This is the Porter-Duff *over* operator from 3.2.2/3.2.4. Where the cloud mask is 0 (no cloud), `sky` shows through unchanged. Where the cloud mask is 1, `cloud_color` (white) wins. In between, the two are alpha-blended proportionally.

For grey storm clouds, replace `cloud_color = [1, 1, 1]` with `cloud_color = [0.6, 0.6, 0.6]`. For sunset clouds, try `cloud_color = [1.0, 0.6, 0.4]`.

<Admonition type="dyk" title="Technical note · how this differs from volumetric clouds">
Real volumetric clouds — used in modern games and film — march rays through a 3D density field, accumulating colour and attenuating light based on scattering integrals. The 2D fake here skips all of that physics; it composites a single-layer cloud mask over a flat sky. The result is convincing for backgrounds and stylised scenes but obviously not for VFX-quality cloud rendering [4].
</Admonition>

<Exercise n={1} kicker="EXECUTE" title="Run the sky generator">

Run `clouds.py` from the downloads. Inspect the output.

**Reflection questions**

- Why does the threshold produce *hard* cloud edges even though fbm is smooth?
- What does setting `gain = 1` (no amplification) do?
- What proportion of the sky is cloudy with `t = 0.45`?

<Dropdown summary="Answers">

**Hard edges** — the threshold creates a step function: below `t` everything goes to 0, above `t` everything starts climbing. The gain steepens the climb so the transition zone (where the cloud is partially opaque) is narrow. Without the threshold, the field would smoothly cover the whole sky with no clear cloud silhouettes.

**Gain 1** — values above `t` map linearly to `[0, 1]`. The cloud body has a *gradient* from threshold to white instead of solid white. Reads as fog, not cumulus.

**Coverage at t = 0.45** — since fbm is roughly uniform in `[0, 1]`, about 55% of pixels exceed 0.45. But the threshold catches *low-frequency* groups (since fbm is smooth), so the visible coverage looks like 30-40% — a typical cumulus sky.

</Dropdown>

</Exercise>

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image
# fbm() from 6.1.1 in scope

H, W = 300, 600

sky_top = np.array([0.25, 0.10, 0.40])         # deep purple
sky_bot = np.array([1.00, 0.55, 0.30])         # vivid orange
yy = np.linspace(0, 1, H)[:, None, None]
sky = sky_top * (1 - yy) + sky_bot * yy
sky = np.broadcast_to(sky, (H, W, 3)).copy()

cloud = fbm((H, W), scale=80, octaves=5, seed=44)
cloud = np.clip((cloud - 0.45) * 4, 0, 1)
cloud_rgb = np.stack([cloud, cloud, cloud], axis=-1)

cloud_top = np.array([0.85, 0.80, 0.95])
cloud_bot = np.array([1.00, 0.80, 0.40])
cloud_color = cloud_top * (1 - yy) + cloud_bot * yy

out = sky * (1 - cloud_rgb) + cloud_rgb * cloud_color
Image.fromarray((np.clip(out, 0, 1) * 255).astype(np.uint8)).save('sunset_clouds.png')
```
</CodeBlock>

**How it works:**

- Sky is the same vertical lerp, with sunset-coloured stops.
- Cloud mask is unchanged; what changes is the cloud *colour*, which is also a vertical lerp.
- The composite multiplies cloud RGB by the cloud-colour gradient, so each cloud takes on its local sunset tint.

</Dropdown>

#### Make it your own

- Add a *second* lower-frequency fbm with a wider threshold — that becomes a base layer of haze underneath the cumulus clouds.
- Move the cloud-mask threshold from a constant to a *vertical gradient* — more clouds in the lower half, fewer near the zenith. Matches real cumulus distribution.
- Generate a frame sequence by gradually shifting `seed` for the cloud noise; the clouds appear to drift across the sky.

</Exercise>

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Procedural cumulus clouds are two ingredients: an fbm field thresholded with `clip((z − t) * gain, 0, 1)` for the cloud mask, and a vertical sky gradient as the background. Compositing the mask over the sky with alpha blending (the Porter-Duff over operator from 3.2.2) gives the final image. Tune `t` for cloud coverage (lower = more cloudy) and `gain` for edge sharpness (higher = crisper). Change cloud colour for mood — white for fair weather, grey for storm, golden for sunset. The two-parameter mask trick scales beyond clouds to any volumetric look — smoke, fog, even fire — where you want "mostly empty plus localised dense regions."

</Admonition>

**Common pitfalls to avoid**

- Forgetting to broadcast `sky` to `(H, W, 3)` — the gradient evaluates as `(H, 1, 3)` and shape errors follow.
- Setting `t` too high — almost no clouds, just empty sky.
- Setting `gain` too low — clouds look like soft Perlin blobs, not crisp cumulus.
- Compositing with `sky * cloud + cloud_color` instead of `sky * (1 - cloud) + cloud_color * cloud` — wrong alpha math, clouds look additive instead of over.
- Using `np.where(cloud > 0.5, cloud_color, sky)` instead of alpha-composite — gives hard edges and loses the soft-shoulder zone.
