## Overview <a id="overview"></a>

A film cut is the cheapest possible scene transition: at frame N, scene A; at frame N+1, scene B. It's the most common transition because it works for almost every emotional beat. But sometimes you want a *transition* rather than a *cut* — a way of telling the viewer "we're moving from there to here over a moment, not instantly." That's the job of the morphing transition.

This lesson covers three classics: **crossfade** (uniform alpha blend over time), **wipe** (alpha varies along an axis, sweeps across), and **mosaic dissolve** (per-tile threshold, tiles flip independently). Every motion-graphics tool, every video editor, every slide deck has these three as the foundation of its transition library. Mechanically each one is a single line of NumPy: `result = a * (1 - α) + b * α`. The interesting variation is *where α comes from*.

### Learning objectives

<ol class="obj-list">
  <li>Implement a crossfade by linearly interpolating two images per frame with a global alpha.</li>
  <li>Implement a horizontal wipe with a per-column alpha that ramps from 0 to 1 across a soft transition band.</li>
  <li>Implement a mosaic dissolve where each tile flips at its own per-tile threshold.</li>
  <li>Recognise these as instances of the same `a * (1 - α) + b * α` blend, with different sources of α.</li>
</ol>

## Quick start — three transitions side by side <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np

def crossfade(a, b, t):
    return (a * (1 - t) + b * t).astype(np.uint8)

def wipe(a, b, t, band_w=80):
    h, w, _ = a.shape
    centre = int((w + band_w) * t - band_w / 2)
    xs = np.arange(w)
    alpha = np.clip((xs - (centre - band_w / 2)) / band_w, 0, 1)
    return (a * (1 - alpha[None, :, None]) + b * alpha[None, :, None]).astype(np.uint8)

def mosaic(a, b, t, tile=20):
    rng = np.random.default_rng(42)
    out = a.copy()
    n_y, n_x = a.shape[0] // tile, a.shape[1] // tile
    thresholds = rng.uniform(0, 1, (n_y, n_x))
    for ty in range(n_y):
        for tx in range(n_x):
            if thresholds[ty, tx] < t:
                y0, x0 = ty * tile, tx * tile
                out[y0:y0+tile, x0:x0+tile] = b[y0:y0+tile, x0:x0+tile]
    return out
```
</CodeBlock>

<Admonition type="tip">
All three transitions are **`a * (1 - α) + b * α`** under the hood. The only thing that varies is how α is computed: a scalar for crossfade, a per-column vector for wipe, a per-tile boolean for mosaic.
</Admonition>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Crossfade: scalar alpha

The simplest transition. A single scalar `t ∈ [0, 1]` blends `a` and `b` uniformly:

`result = a * (1 - t) + b * t`

At `t = 0` you see only `a`; at `t = 1` you see only `b`; at `t = 0.5` you see both equally. The crossfade has no spatial structure — every pixel transitions at the same time and rate. Reads as a "soft dissolve" or "fade through."

In Adobe Premiere this is called "Cross Dissolve"; in Final Cut Pro, "Cross Dissolve"; in DaVinci Resolve, "Cross Dissolve" — the same primitive across every NLE.

### Concept 2 — Wipe: per-column alpha

A wipe replaces the scalar α with a **per-column** vector. The transition moves across the screen rather than happening everywhere at once:

<CodeBlock lang="python" file="wipe.py">
```python
band_centre = int((w + band_w) * t - band_w / 2)
alpha = np.clip((xs - (band_centre - band_w / 2)) / band_w, 0, 1)
```
</CodeBlock>

At `t = 0`, the band is off-screen left (alpha is 0 everywhere). At `t = 0.5`, the band is at the middle (alpha is 0 on the left, 1 on the right, smooth ramp in between). At `t = 1`, the band has passed off-screen right (alpha is 1 everywhere).

The `band_w = 80` parameter is the soft edge of the wipe — how many pixels wide the transition band is. Hard wipes (`band_w = 1`) look like a vertical line sweeping across; soft wipes look like a feather-edged shadow. Modern UI conventions favour soft wipes.

<Admonition type="dyk" title="Did you know · the iris wipe is iconic">
The **iris wipe** — a circular hole that opens or closes — was the standard transition in silent-era films. Charlie Chaplin's films are full of them. Modern editors use it for stylised "old-film" effects. The math is the same as the linear wipe; α depends on radial distance from a fixed centre instead of horizontal distance from a moving band [1].
</Admonition>

### Concept 3 — Mosaic dissolve: per-tile thresholds

The most expressive of the three. Divide the image into a grid of tiles; assign each tile a random threshold in $[0, 1]$; at frame `t`, a tile shows `b` if its threshold is less than `t`, otherwise `a`.

<CodeBlock lang="python" file="mosaic.py">
```python
rng = np.random.default_rng(42)
thresholds = rng.uniform(0, 1, (n_y, n_x))

# At each frame:
for ty in range(n_y):
    for tx in range(n_x):
        if thresholds[ty, tx] < t:
            out[y0:y0+tile, x0:x0+tile] = b[y0:y0+tile, x0:x0+tile]
```
</CodeBlock>

At `t = 0` no tile is flipped — all `a`. At `t = 1` every tile has flipped — all `b`. In between, a random scatter of tiles in different stages. The fixed seed keeps the threshold pattern stable across frames so each tile flips at exactly one moment.

Vary the tile size and you get very different looks: 5×5 tiles look like grain; 50×50 tiles look like a deliberate stylistic choice. Vary the threshold distribution and you can make a directional dissolve (e.g., tiles in the top-left flip first by adding `(ty + tx) / (n_y + n_x)` to the threshold).

<Admonition type="important">
The three transitions form a hierarchy of α complexity: scalar (crossfade), 1D (wipe), 2D (mosaic). Each is a special case of the next. A scalar α is a 1D α that's constant; a 1D α is a 2D α that's constant along rows. The same blend formula handles all three.
</Admonition>

**Reflection questions**

- The crossfade at `t = 0.5` shows both scenes at half opacity. Why does this often look muddy or muted?
- The wipe band is 80 pixels wide. What does `band_w = 1` look like? `band_w = 200`?
- The mosaic threshold is uniformly distributed in $[0, 1]$. What does a non-uniform distribution look like?

<Dropdown summary="Answers">

**Crossfade muddiness** — at `t = 0.5`, every pixel is the arithmetic mean of two values. Two saturated colours often average to a desaturated grey (red + cyan = grey). This is a perceptual phenomenon — the eye sees "loss of saturation" as "muddy." Avoid crossfades for transitions where both scenes have strong, distinct colour palettes.

**Wipe band width** — `band_w = 1` is a hard vertical line moving across (no soft edge). Reads as a "sliding curtain." `band_w = 200` is a very soft transition, almost a horizontal-direction crossfade. Pick width based on desired mood: snappy wipe = narrow, dreamy = wide.

**Non-uniform thresholds** — clumping thresholds toward 0 makes the dissolve "finish early"; clumping toward 1 makes it "build up slowly." Replace `rng.uniform` with `rng.beta(2, 5)` for a slow start, fast finish. Or use position-based thresholds (`thresholds[ty, tx] = (ty + tx) / (n_y + n_x)`) for a directional sweep.

</Dropdown>

</Exercise>

A diagonal sweep, top-left to bottom-right. Useful for stylised "wipe with momentum" effects.

- **Hexagonal mosaic.** Replace square tiles with hexagonal ones — looks more organic and reads as "honeycomb dissolve."
- **Noise-driven wipe.** Add 2D Perlin noise to the alpha map (you'll cover Perlin in 6.1.1). The wipe gets a "torn paper" edge.
- **Multi-stage transition.** Compose two transitions sequentially: a wipe to a midway state, then a crossfade to the final state.

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Every scene-to-scene transition is a per-pixel blend `a * (1 - α) + b * α`. The transition flavour comes from how α is computed: a scalar (crossfade), a per-column vector (wipe), a per-tile boolean (mosaic). All three are single-line NumPy operations. The math is shared; the geometry is the design choice. Adding a soft edge to the wipe or distributing the mosaic thresholds in a non-uniform way gives expressive variations on the same core operation. The pattern extends to radial wipes (iris), Perlin-noise wipes (torn-paper), and 3D rotational wipes (page-turn) — same blend formula, more interesting α maps.

</Admonition>

**Common pitfalls to avoid**

- **Crossfade between very different palettes.** Muddy midpoint. Use a wipe instead.
- **Hard-edge wipe by default.** Looks like a curtain not a transition. Use a soft edge unless the look you want is "hard cut on the move."
- **Per-frame threshold generation.** Recomputing the mosaic thresholds every frame makes tiles flicker. Generate once outside the frame loop and reuse.
- **Forgetting the alpha broadcast.** `alpha[None, :, None]` adds the unit axes needed to broadcast across `(H, W, C)`. Without them, the multiply fails.
