## Overview <a id="overview"></a>

Two of the most iconic procedural textures — *marble* and *wood* — share a single recipe: take a smooth periodic carrier (a sine wave), then *displace* it by a turbulence field built from fbm noise. The result looks like organic material because real marble veins and real wood rings have the same mathematical structure: a regular underlying pattern broken by smaller-scale irregularities [1]. Ken Perlin himself first published the marble example in 1985 as the canonical use case for his new noise function; the wood texture was added by Loren Carpenter and the *Texturing and Modeling* book in 1994 [2].

### Learning objectives

<ol class="obj-list">
  <li>Express marble as `sin(x + turbulence(x, y))` — a horizontal stripe pattern displaced by noise.</li>
  <li>Express wood as `sin(r + turbulence(x, y))` where `r` is distance from a centre — concentric rings displaced by noise.</li>
  <li>Map the resulting `[0, 1]` field to a two-stop colour ramp (white/grey for marble, brown/tan for wood).</li>
  <li>Tune the carrier frequency (vein/ring spacing) and turbulence amplitude (irregularity) for different visual results.</li>
</ol>

## Quick start — marble veins <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image
# fbm() from 6.1.1 in scope

H, W = 400, 400
noise = fbm((H, W), scale=60, octaves=5, seed=7 + 80)

y, x = np.indices((H, W)).astype(np.float64)
marble = np.sin((x / W * 6 + noise * 4) * np.pi)        # vertical veins, noise-displaced
marble = (marble - marble.min()) / (marble.max() - marble.min())

# Two-stop colour ramp — warm off-white to cool grey
warm = np.array([0.95, 0.92, 0.85])
cool = np.array([0.45, 0.45, 0.50])
rgb = marble[..., None] * warm + (1 - marble[..., None]) * cool

Image.fromarray((np.clip(rgb, 0, 1) * 255).astype(np.uint8)).save('marble.png')
```
</CodeBlock>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Marble: periodic carrier + noise displacement

A marble vein is "a periodic pattern with noisy displacement." The recipe is direct:

```python
veins = np.sin((x / W * frequency + noise * amplitude) * np.pi)
```

- `x / W * frequency * π` is the **carrier** — a clean periodic function. `frequency = 6` gives 3 full vein cycles across the canvas (sin has period 2π).
- `noise * amplitude * π` is the **displacement** — fbm noise that *modulates* the carrier's phase. `amplitude = 4` means the noise shifts the sine phase by up to 4π.
- The sum goes through `sin`, producing a smooth oscillation between -1 and 1 that follows the noise-displaced carrier [3].

The result captures what real marble looks like: regular vein spacing (from the carrier), but every individual vein wavers, twists, and varies in thickness (from the displacement).

### Concept 2 — Wood: radial carrier + noise displacement

Wood is structurally the same algorithm with a *different carrier*. Trees lay down concentric annual growth rings; the rings have regular spacing in their pristine form (the carrier), but real wood has irregularities (the displacement). Substitute the distance from a centre for the linear x-coordinate:

```python
y, x = np.indices((H, W)).astype(np.float64)
cy, cx = H / 2, W / 2
r = np.sqrt((y - cy) ** 2 + (x - cx) ** 2) / RING_WIDTH

wood = np.sin((r + noise * amplitude) * 2 * np.pi)
```

The same `sin(carrier + noise)` formula now produces concentric rings. The centre of the radial coordinate is the *pith* (the heart of the tree); the rings spread outward. Real tree-ring archaeology builds on exactly this structure.

### Concept 3 — Two-stop colour ramps

The `sin(...)` field gives values in `[-1, 1]`; normalise to `[0, 1]` and treat as an interpolation parameter between two stop colours:

```python
field01 = (field - field.min()) / (field.max() - field.min())
rgb = field01[..., None] * stop_a + (1 - field01[..., None]) * stop_b
```

For marble: `stop_a = warm off-white`, `stop_b = cool grey`. For wood: `stop_a = light tan`, `stop_b = dark brown`. The same lerp formula handles both — only the two stop colours change.

Three-stop ramps (using `np.where` to split the field into "below 0.5" and "above 0.5") give richer palettes — try black/grey/warm-white for dramatic marble [4].

<Admonition type="dyk" title="Technical note · Perlin's original recipe">
Ken Perlin's 1985 SIGGRAPH paper introducing noise included a marble texture as the demonstration of the function's usefulness. The original formula was `marble = sin(x + turbulence(x, y, z))` evaluated in 3D for solid-textured marble columns. The 2D form here is a planar slice of the same idea [1].
</Admonition>

Run `textures.py` from the downloads. It produces both `marble.png` and `wood.png`.

**Reflection questions**

- What happens if you set the noise amplitude to 0 (`noise * 0`)?
- Why does the wood texture have an obvious *centre* while the marble does not?
- The marble veins run *vertically* in the quick start. How do you make them run horizontally?

<Dropdown summary="Answers">

**Amplitude 0** — no noise displacement. The marble becomes perfectly straight vertical stripes; the wood becomes perfectly circular concentric rings. Useful as a debug — confirms the carrier is correct.

**Wood has a centre** — the carrier `r = sqrt((y - cy)² + (x - cx)²)` is anchored at `(cy, cx)`. The carrier defines the geometric centre. The marble carrier `x` has no centre — it is linear in one direction.

**Horizontal veins** — replace `x / W * 6` with `y / H * 6`. Now the carrier varies vertically, so veins run horizontally.

</Dropdown>

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image
# fbm() from 6.1.1 in scope

H, W = 250, 250
noise = fbm((H, W), scale=60, octaves=5, seed=33)

y, x = np.indices((H, W)).astype(np.float64)
cy, cx = H / 2, W / 2

mx = np.sin((x / W * 6 + noise * 4) * np.pi)
r  = np.sqrt((y - cy) ** 2 + (x - cx) ** 2) / 40
wo = np.sin((r + noise * 1.2) * 2 * np.pi)

def ramp(field, a, b):
    f = (field - field.min()) / (field.max() - field.min())
    return f[..., None] * a + (1 - f[..., None]) * b

m_warm = ramp(mx, np.array([0.95, 0.92, 0.85]), np.array([0.45, 0.45, 0.50]))
m_blue = ramp(mx, np.array([0.90, 0.92, 0.98]), np.array([0.20, 0.35, 0.60]))
w_warm = ramp(wo, np.array([0.65, 0.45, 0.25]), np.array([0.30, 0.18, 0.08]))
w_green = ramp(wo, np.array([0.55, 0.65, 0.30]), np.array([0.20, 0.30, 0.10]))

GAP = 6
gap_h = np.zeros((H, GAP, 3))
gap_v = np.zeros((GAP, 2 * W + GAP, 3))
row1 = np.hstack([m_warm, gap_h, m_blue])
row2 = np.hstack([w_warm, gap_h, w_green])
grid = np.vstack([row1, gap_v, row2])

Image.fromarray((np.clip(grid, 0, 1) * 255).astype(np.uint8)).save('texture_grid.png')
```
</CodeBlock>

**How it works:**

- The marble and wood fields are computed once.
- Four separate `ramp` calls produce four colour variants — same field, different palette.
- The 2×2 grid uses the same `hstack`/`vstack` pattern from 3.3.2.

</Dropdown>

#### Make it your own

- Add a third stop colour to the ramp using `np.where` — black-grey-white for dramatic veined marble.
- Multiply the wood texture by an *envelope* (1 − `(r/RADIUS)`) so the rings fade at the edges, simulating a tree cross-section with bark.
- Use Worley noise (6.1.3) as the displacement instead of fbm — produces cellular vein structures instead of swirling ones.

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Marble and wood textures share one recipe: `sin(carrier + noise * amplitude)`. The carrier sets the regular underlying pattern — linear `x` for marble veins, radial `r` for wood rings; the noise displaces the carrier's phase, producing the organic irregularity. Map the `[0, 1]` field through a two-stop colour ramp for the final appearance — warm white/grey for marble, brown/tan for wood. Tuning is two knobs: carrier frequency controls feature spacing; noise amplitude controls irregularity. The same `sin(periodic + noise)` template extends to any procedural texture where regularity meets organic variation — striated stone, layered rock, even striped textiles.

</Admonition>

**Common pitfalls to avoid**

- Forgetting `* np.pi` in the carrier — sin's period is 2π, not 1; without the multiplier, only a fraction of a cycle fits the canvas.
- Setting noise amplitude too high — phase displacement overwhelms the carrier; veins become chaotic.
- Using `* π` for wood (matching marble) instead of `* 2 * π` — wood needs both positive and negative phases to make full rings.
- Forgetting to normalise the `sin` output to `[0, 1]` before the ramp — colours come out inverted or clipped.
- Using the same seed for marble and wood in side-by-side composition — both fields end up with correlated turbulence; pick different seeds.
