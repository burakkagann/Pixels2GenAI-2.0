## Overview <a id="overview"></a>

Two chemicals on a grid. One feeds the other, the other consumes the first. Both diffuse outward into their neighbours. Run this loop a few thousand times and the grid spontaneously breaks into spots, stripes, or maze-like labyrinths — patterns that match the pigment cells on a giraffe, the scales of a tropical fish, and the cracks in dried mud [1].

This lesson implements the **Gray-Scott reaction-diffusion model** in NumPy. It builds directly on the convolution idea introduced in cellular automata, but here the cells hold continuous concentrations rather than binary states.

### Learning objectives

<ol class="obj-list">
  <li>Understand how two coupled differential equations produce emergent spatial patterns.</li>
  <li>Implement diffusion on a grid using a SciPy convolution with a Laplacian kernel.</li>
  <li>Tune the feed and kill rates to switch between spots, stripes, and labyrinths.</li>
</ol>

## Quick start — one step of Gray-Scott <a id="quick-start"></a>

Run this code to perform a single iteration of the Gray-Scott equations on a 128x128 grid seeded with a small patch of chemical V at the centre:

<CodeBlock lang="python" file="gray_scott_step.py">
```python
import numpy as np
from PIL import Image
from scipy.ndimage import convolve

# Initialise two chemical concentrations on a 128x128 grid
size = 128
chemical_u = np.ones((size, size))   # U starts at 1 everywhere
chemical_v = np.zeros((size, size))  # V starts at 0

# Seed a small patch of V near the centre to break symmetry
chemical_v[60:68, 60:68] = np.random.random((8, 8)) * 0.5

# Parameters tuned for spot patterns
feed_rate = 0.055
kill_rate = 0.062
diffusion_u = 0.16
diffusion_v = 0.08

# Laplacian kernel (5-point stencil with diagonal weights)
laplacian_kernel = np.array([[0.05, 0.2, 0.05],
                             [0.2, -1.0, 0.2],
                             [0.05, 0.2, 0.05]])

# Compute Laplacians via convolution (wrap = toroidal boundary)
laplacian_u = convolve(chemical_u, laplacian_kernel, mode='wrap')
laplacian_v = convolve(chemical_v, laplacian_kernel, mode='wrap')

# Apply Gray-Scott reaction-diffusion equations
reaction = chemical_u * chemical_v * chemical_v
chemical_u += diffusion_u * laplacian_u - reaction + feed_rate * (1 - chemical_u)
chemical_v += diffusion_v * laplacian_v + reaction - (feed_rate + kill_rate) * chemical_v

# Visualise V (patterns appear in this chemical)
pattern = (chemical_v * 255).astype(np.uint8)
Image.fromarray(pattern).save('gray_scott_step.png')
```
</CodeBlock>

<Admonition type="tip">
A single step is not enough to see patterns emerge — the system needs thousands of iterations. The quick-start above is a single step. Exercise 1 wraps it in a loop.
</Admonition>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — The Gray-Scott equations

Reaction-diffusion was first described by Alan Turing in 1952 as a possible mechanism for biological pattern formation [2]. The Gray-Scott model uses two chemicals, **U** and **V**, that interact through this reaction:

**U + 2V → 3V**

One molecule of U combined with two of V produces three V's. The model adds two more processes:

- **Feed**: U is replenished from outside at rate `f`.
- **Kill**: V decays at rate `f + k`.
- **Diffusion**: both chemicals spread to neighbours at their own rates.

The discretised update rules for one time step are:

**U += D_u · ∇²U − UV² + f(1 − U)**
**V += D_v · ∇²V + UV² − (f + k)V**

where ∇² is the Laplacian (a measure of how much each cell differs from its neighbours) [3].

### Concept 2 — The Laplacian as a convolution

The Laplacian operator measures how much a cell's value differs from the average of its surroundings. On a grid, this is computed by convolving with a small kernel:

<CodeBlock lang="python">
```python
# Five-point Laplacian (standard form)
basic = np.array([[ 0,  1,  0],
                  [ 1, -4,  1],
                  [ 0,  1,  0]])

# Nine-point Laplacian (includes diagonals; smoother)
gray_scott = np.array([[0.05, 0.2, 0.05],
                       [0.2, -1.0, 0.2],
                       [0.05, 0.2, 0.05]])
```
</CodeBlock>

The nine-point kernel is preferred for Gray-Scott because it reduces directional bias — the resulting patterns look more isotropic. Convolving the chemical field with this kernel via `scipy.ndimage.convolve` produces the discrete Laplacian in a single vectorised pass [4].

<Admonition type="note">
The `mode='wrap'` argument makes the grid toroidal — the right edge connects to the left, the top to the bottom. Without it, the boundaries would behave as zero-padded walls that distort patterns near the edges.
</Admonition>

### Concept 3 — Parameter regimes

Small changes to `feed_rate` and `kill_rate` produce dramatically different patterns. Common regimes [5]:

| Pattern | feed | kill |
|---------|------|------|
| Spots | 0.055 | 0.062 |
| Stripes / labyrinth | 0.029 | 0.057 |
| Coral / chaos | 0.060 | 0.062 |
| Solitons (moving spots) | 0.030 | 0.062 |

These values are not arbitrary; they sit in narrow corridors of stability where the reaction terms balance the diffusion rates. Outside these corridors, V either floods the grid or dies out completely. Exercise 2 explores this parameter space.

## Exercises <a id="exercises"></a>

<Exercise n={1} kicker="EXECUTE" title="Run a full simulation">

The quick-start performed only one step. Wrap it in a loop to evolve the system for several thousand iterations and watch the pattern emerge.

<CodeBlock lang="python" file="exercise1_loop.py">
```python
import numpy as np
from PIL import Image
from scipy.ndimage import convolve

size = 128
n_steps = 5000

chemical_u = np.ones((size, size))
chemical_v = np.zeros((size, size))
chemical_v[60:68, 60:68] = np.random.random((8, 8)) * 0.5

feed_rate, kill_rate = 0.055, 0.062
diffusion_u, diffusion_v = 0.16, 0.08

laplacian_kernel = np.array([[0.05, 0.2, 0.05],
                             [0.2, -1.0, 0.2],
                             [0.05, 0.2, 0.05]])

for _ in range(n_steps):
    lap_u = convolve(chemical_u, laplacian_kernel, mode='wrap')
    lap_v = convolve(chemical_v, laplacian_kernel, mode='wrap')
    reaction = chemical_u * chemical_v * chemical_v
    chemical_u += diffusion_u * lap_u - reaction + feed_rate * (1 - chemical_u)
    chemical_v += diffusion_v * lap_v + reaction - (feed_rate + kill_rate) * chemical_v

pattern = (chemical_v * 255).astype(np.uint8)
Image.fromarray(pattern).save('gray_scott_spots.png')
```
</CodeBlock>

**Reflection questions**

- Why does the pattern not appear after 100 steps? How many are typically needed?
- What happens if the central seed is removed entirely (`chemical_v` left at zero everywhere)?
- The simulation is deterministic — same seed, same pattern. Why is `np.random.random` used to initialise V?

<Dropdown summary="Solution & explanation">

**Answers:**

- Reaction-diffusion is **slow**. The chemicals must diffuse across the grid and react many times before structures stabilise. 5,000-20,000 steps is typical for a 128x128 grid.
- With no perturbation, the system stays at the homogeneous equilibrium (U=1, V=0) forever. The small random patch breaks the symmetry and gives the equations something to amplify.
- The random initialisation creates an uneven seed. A uniform seed would produce a perfectly symmetric pattern; randomness lets organic-looking variations grow from natural differences between neighbouring cells [5].

</Dropdown>

</Exercise>

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image
from scipy.ndimage import convolve

size = 128
n_steps = 5000

chemical_u = np.ones((size, size))
chemical_v = np.zeros((size, size))
chemical_v[60:68, 60:68] = np.random.random((8, 8)) * 0.5

feed_rate, kill_rate = 0.055, 0.062
diffusion_u, diffusion_v = 0.16, 0.08

laplacian_kernel = np.array([[0.05, 0.2, 0.05],
                             [0.2, -1.0, 0.2],
                             [0.05, 0.2, 0.05]])

for _ in range(n_steps):
    lap_u = convolve(chemical_u, laplacian_kernel, mode='wrap')
    lap_v = convolve(chemical_v, laplacian_kernel, mode='wrap')
    reaction = chemical_u * chemical_v * chemical_v
    chemical_u += diffusion_u * lap_u - reaction + feed_rate * (1 - chemical_u)
    chemical_v += diffusion_v * lap_v + reaction - (feed_rate + kill_rate) * chemical_v

red = np.clip((1 - chemical_u) * 255, 0, 255).astype(np.uint8)
blue = np.clip(chemical_v * 255, 0, 255).astype(np.uint8)
green = np.zeros_like(red)

rgb = np.stack([red, green, blue], axis=2)
Image.fromarray(rgb).save('gray_scott_color.png')
```
</CodeBlock>

**How it reads**

Red regions show where U has been depleted (consumed by the reaction); blue regions show high V. Spots become magenta-rimmed because U is most depleted at the edges of each V spot, where the reaction rate peaks. The colour visualisation makes the underlying chemistry legible at a glance.

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Reaction-diffusion systems show how local rules and slow diffusion can produce global patterns that look biological. The Gray-Scott model needs only two chemicals, two reaction terms, and a Laplacian — yet covers a parameter space rich enough to reproduce spots, stripes, coral, and moving solitons. The Laplacian, implemented as a SciPy convolution with a 3x3 kernel, is the same building block used in image edge detection and in cellular automata. Tuning `feed_rate` and `kill_rate` together — not independently — is essential, because the system has narrow stability corridors.

</Admonition>

**Common pitfalls to avoid**

- Forgetting `mode='wrap'` on the convolution produces edge artifacts.
- Setting `n_steps` too low (under 1000) shows no pattern — the system is still equilibrating.
- Floating-point chemicals can drift outside [0, 1] in principle; clip when converting to uint8 for display.
