## Big question <a id="big-question"></a>

*Where does a neural network 'look' when it makes a prediction?* For a CNN classifying an image as "dog," is it the dog's face, the texture of fur, or possibly an unrelated background detail? **Attention visualisation** is the family of techniques for answering this question. **Class Activation Maps** (Zhou et al. 2016) overlay a heatmap on the input showing which pixels contributed most to the chosen class [1]. **Self-attention maps** in transformers do the same thing for language — showing which words the model attended to when generating each output token [2]. Both are interpretability tools that double as artistic primitives.

  <li>Composite the attention map onto the input as a warm-colour overlay.</li>
  <li>Distinguish CAM (gradient-based attention for CNNs) from self-attention (learned attention in transformers).</li>
</ol>

## Part 1 — Attention as a 2D weight grid <a id="part-1"></a>

An attention map is just a 2D field `α(y, x) ∈ [0, 1]` saying how important each pixel is to the network's decision. High values are bright regions of the heatmap; low values are dim.

```python
attention = compute_attention(network, image, target_class)   # shape (H, W)
attention = (attention - attention.min()) / (attention.max() - attention.min())
```

The standard visualisation overlays this map on the input image with a warm colour scheme — red where attention is high, transparent where low.

```python
heat = np.zeros_like(image_rgb)
heat[..., 0] = attention                  # red channel
heat[..., 1] = attention * 0.4            # some yellow
out = image_rgb * (1 - attention[..., None] * 0.6) \
    + heat * (attention[..., None] * 0.6)
```

## Part 2 — CAM (Class Activation Maps) <a id="part-2"></a>

The simplest CAM construction: take the activations from the *final convolutional layer* (before the classifier), weight each channel by the classifier's weights for the target class, and sum:

```python
def cam(feature_maps, class_weights):
    # feature_maps: (H, W, C); class_weights: (C,)
    return np.sum(feature_maps * class_weights[None, None, :], axis=-1)
```

The result is a low-resolution attention map (the size of the feature maps, typically 7×7 for a 224×224 input). Upsample to input resolution and overlay [1].

**Grad-CAM** (Selvaraju et al. 2017) generalises this to any layer by computing gradient-based importance weights instead of using classifier weights directly. The resulting attention maps are higher-fidelity than vanilla CAM and work with any architecture, not just CNNs with a global-average-pool head [3].

## Part 3 — Self-attention in transformers <a id="part-3"></a>

Transformer models (Vaswani et al. 2017) use *self-attention*: each token in the sequence computes attention weights over every other token, and uses those weights to mix the value vectors [2]. Visualising the attention matrix shows what the model considered relevant for each output position.

For images, **Vision Transformers** (Dosovitskiy et al. 2020) chop the image into patches and apply the same self-attention; their attention maps highlight which patches the model attended to when classifying [4].

The visualisation in both cases is the same as for CAM: a 2D map overlaid on the input. The *computation* is different (gradient-based for CAM, learned for self-attention), but the artistic and interpretive value is identical.

<Admonition type="dyk" title="Technical note · attention is interpretable but not causal">
A common misconception is that high attention weight means "the model used this region to make its decision." That's not necessarily true. Attention maps show *correlation* with the prediction, not *causation*. A model can have high attention on irrelevant regions and still make correct predictions (or vice versa). Several papers in 2019–2020 (Jain & Wallace, *"Attention is not Explanation"*) argued for caution in interpreting attention as a faithful explanation [5].
</Admonition>

## Synthesis project <a id="synthesis"></a>

<Exercise n={1} kicker="EXECUTE" title="Render an attention overlay">

Run `attention_overlay.py` from the downloads. It generates a synthetic input image (a noisy background with bright disc and rectangle), builds an attention map as the sum of two Gaussian blobs over the salient regions, and overlays the heatmap as a warm-colour wash.

**Reflection questions**

- Why does the overlay reduce the brightness of *unattended* regions?
- The synthetic attention map is hand-crafted. In a real CNN, what determines where the bright regions are?
- What happens if the attention map is uniform (every pixel has the same weight)?

<Dropdown summary="Answers">

**Dim unattended regions** — the alpha-blend formula `image × (1 − α × 0.6) + heat × (α × 0.6)` reduces image intensity proportional to attention. Where α is low, the image stays. Where α is high, the heat colour replaces it.

**Real CNN attention** — determined by the trained network's response. Late-layer feature maps activate strongly where the input matches what the network is looking for. CAM amplifies these activations into a clean attention map.

**Uniform attention** — uniform red wash over everything. No information about *what* the model looked at; the visualisation is useless.

</Dropdown>

</Exercise>

<Exercise n={2} kicker="MODIFY" title="Three colour schemes for the overlay">

Edit `attention_overlay.py` for these goals.

**Goals**

1. **Cool overlay** — blue instead of red for "low-attention" highlighting.
2. **Inverted** — dim the *attended* regions, brighten the unattended.
3. **Channel-coded** — show attention on the green channel; keep the original on red and blue.

<Dropdown summary="Code snippets">

```python
# Cool overlay
heat[..., 2] = attention
heat[..., 1] = attention * 0.4

# Inverted (de-emphasise the salient regions)
out = image_rgb * attention[..., None] + grey * (1 - attention)[..., None]

# Channel-coded
out = image_rgb.copy()
out[..., 1] = np.clip(out[..., 1] + attention * 0.5, 0, 1)
```

The exercise builds intuition for the *aesthetic* dimension of attention visualisation. The same data can read as "highlight" or "spotlight" depending on how it's rendered.

</Dropdown>

</Exercise>

<Exercise n={3} kicker="CREATE" title="A CAM from a tiny CNN">

Build a tiny CNN (use the architecture from 9.2.2), train it on a synthetic 2-class image dataset (round things vs square things), and compute a real CAM. Compare it to the hand-crafted attention map.

<Dropdown summary="Approach">

```python
# After training:
def cam_for_class(net, image, class_idx):
    feature_maps = net.forward_to_last_conv(image)   # (H', W', C)
    class_weights = net.classifier_weights[class_idx]  # (C,)
    cam = np.sum(feature_maps * class_weights[None, None, :], axis=-1)
    cam = np.maximum(cam, 0)                         # ReLU
    cam = upsample(cam, image.shape[:2])             # to input size
    return cam / cam.max()
```

If your CNN has learned anything, the CAM should focus on the *centre* of round objects when predicting "round," and on the *corners* of square objects when predicting "square." This is the most basic version of one of the most-cited interpretability techniques in deep learning.

</Dropdown>

</Exercise>
