## Overview <a id="overview"></a>

Drop a stone in a pond and circular waves spread outward from the impact. Drop two stones at the same time and the waves overlap, *adding* where their peaks coincide and *cancelling* where peaks meet troughs. The bright ridges and dark hollows of the resulting pattern are the basis of every interference phenomenon in physics — light, sound, water, electron beams, gravity waves [1]. Thomas Young used the same construction in 1801 to demonstrate that light is a wave; *Young's double-slit experiment* is one of the foundational images of modern physics [2]. This lesson generates N-source interference patterns in NumPy and shows that the entire phenomenon is one sum of cosines over distance fields.

### Learning objectives

<ol class="obj-list">
  <li>Build a circular wave from a point source as `cos(distance(x, y, source) / wavelength)`.</li>
  <li>Sum waves from multiple sources to get the interference pattern.</li>
  <li>Identify constructive and destructive interference in the output — bright ridges and dark hollows.</li>
  <li>Add a `1/(1 + distance)` amplitude decay to model the natural energy spread of expanding wavefronts.</li>
</ol>

## Quick start — three-source interference <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image

H, W = 400, 400
sources = [(100, 100), (300, 100), (200, 300)]

y, x = np.indices((H, W)).astype(np.float64)
field = np.zeros((H, W))

for sy, sx in sources:
    r = np.sqrt((y - sy) ** 2 + (x - sx) ** 2)
    field += np.cos(r / 5) / (1 + r / 80)        # waveform + amplitude decay

field = (field - field.min()) / (field.max() - field.min())
Image.fromarray((field * 255).astype(np.uint8), 'L').save('wave_interference.png')
```
</CodeBlock>

The whole simulation is one expression — `cos(distance / wavelength)` per source, divided by an amplitude falloff, summed across sources. No time-stepping, no PDE. This is the *steady-state* interference assuming all sources have the same frequency and phase.

## Core concepts <a id="core-concepts"></a>

### Concept 1 — A circular wave from a point source

The wave from a point source at `(sy, sx)` is a function of the distance `r` from that source:

```python
r = np.sqrt((y - sy) ** 2 + (x - sx) ** 2)
wave = np.cos(r / wavelength)
```

`r / wavelength` is the wave's *phase* at each pixel; the cosine maps phase to amplitude. Where `r` is a multiple of `2π · wavelength`, the wave is at its peak; halfway between, at its trough. The result is a set of concentric rings.

In a real medium (water, air), the wave's amplitude falls off as it spreads outward — energy conservation says the wave's intensity per area decays as `1/r²` in 3D, but in 2D it decays as `1/r` (or any roughly-inverse function for pedagogy). The `1 / (1 + r / scale)` form keeps the amplitude finite at the source and decays smoothly outward [3].

### Concept 2 — Summing for interference

The principle of superposition says: when multiple waves coexist, the total displacement at any point is the *sum* of their individual displacements. In NumPy:

```python
for source in sources:
    field += wave_from(source)
```

Where the sum is large (positive), constructive interference: peaks add up. Where the sum is near zero, destructive interference: peaks cancel troughs. The pattern of bright and dark you see is the spatial map of constructive and destructive interference [4].

For two coherent point sources (same wavelength, same phase), the constructive interference forms **hyperbolic curves** anchored on the two sources. These curves are the locus of points where the path difference from the two sources is an integer multiple of the wavelength — exactly Thomas Young's 1801 derivation [2].

### Concept 3 — Amplitude decay

Without amplitude decay, all sources contribute equally regardless of distance, and the interference pattern looks unnaturally even. With decay, sources fade with distance:

```python
amplitude = 1 / (1 + r / decay_scale)
field += amplitude * np.cos(r / wavelength)
```

The `1 + r / decay_scale` keeps the source from going to infinity at `r = 0`. Setting `decay_scale = 80` means the amplitude drops to half at 80 pixels from the source, to a third at 160 pixels, etc.

The decay makes the pattern look like *real water waves* — strongest near the source, weaker as the wave fronts spread outward. Without it the pattern is more abstract and uniform, useful for stylised effects but less physically credible.

<Admonition type="dyk" title="Technical note · Young's double slit">
Thomas Young's 1801 experiment was the first convincing demonstration that light is a wave. He passed light from a single source through two parallel slits and observed an interference pattern on a screen behind the slits. The fringe spacing matched his prediction from the two-source interference geometry — the same calculation you can derive from a 2D version of this lesson's two-source quick start [2].
</Admonition>

<Exercise n={1} kicker="EXECUTE" title="Run the 3-source interference">

Run `wave_interference.py` from the quick start.

**Reflection questions**

- Why do the rings appear *brighter* near each source?
- Where in the image is the strongest constructive interference?
- What happens if you set `wavelength = 50` (much larger than the source separation)?

<Dropdown summary="Answers">

**Brighter near sources** — the `1 / (1 + r / 80)` amplitude decay. At the source pixel `r = 0` → amplitude = 1; at large distances → amplitude → 0.

**Strongest constructive** — at points where all three source distances are simultaneously near multiples of the wavelength. These appear as the brightest spots in the pattern.

**Large wavelength** — fewer rings per source; the cosine takes more pixels to cycle. The interference still happens but at lower spatial frequency — the pattern looks softer and less detailed.

</Dropdown>

</Exercise>

<Exercise n={2} kicker="MODIFY" title="Young's double-slit experiment">

Edit the script to model Thomas Young's experiment: just two sources, no amplitude decay (so the contribution from each is equal).

**Goals**

1. **Two sources** — replace the source list with `[(200, 120), (200, 280)]`.
2. **No decay** — drop the `1 / (1 + r / 80)` term.
3. **Larger wavelength** — `cos(r / 8)` so the fringes are wider and easier to see.

<Dropdown summary="Goal — what to expect">

```python
sources = [(200, 120), (200, 280)]
field = np.zeros((H, W))
for sy, sx in sources:
    r = np.sqrt((y - sy)**2 + (x - sx)**2)
    field += np.cos(r / 8)
```

A classical two-source interference pattern. Bright hyperbolic curves emerge from the line connecting the two sources, fanning outward. Each curve traces points where the path difference equals an integer multiple of the wavelength — the same pattern Young observed in 1801.

</Dropdown>

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image

H, W = 400, 400
sources = [(200, 80), (200, 160), (200, 240), (200, 320)]
phases  = [0, np.pi/2, np.pi, 3*np.pi/2]
WAVELENGTH = 8

y, x = np.indices((H, W)).astype(np.float64)
field = np.zeros((H, W))
for (sy, sx), phi in zip(sources, phases):
    r = np.sqrt((y - sy)**2 + (x - sx)**2)
    field += np.cos(r / WAVELENGTH + phi) / (1 + r / 100)

field = (field - field.min()) / (field.max() - field.min())
Image.fromarray((field * 255).astype(np.uint8), 'L').save('phased_array.png')
```
</CodeBlock>

**How it works:**

- Each source has its own phase offset, so the cosine waves *start* at different points in their cycle.
- The pattern has a clear directionality — interference reinforces in one direction relative to the array, partly cancels in others.
- This is the basis of beam-steering antennas, ultrasound transducers, and phased-array radar.

</Dropdown>

#### Make it your own

- Animate by gradually changing the phase offsets — the beam *sweeps* across the canvas.
- Render the interference as colour: positive values one hue, negative the complementary hue. The pattern becomes a vivid abstract.
- Use the magnitude `|field|` instead of `field` — emphasises the bright nodes without the dark counterparts, useful for "energy concentration" visualisations.

</Exercise>

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

Wave interference is the sum of cosine waves emanating from N point sources. Each source contributes `cos(distance / wavelength)` modulated by a `1 / (1 + distance / decay)` amplitude falloff; summing the contributions gives the interference field. Constructive interference (bright ridges) appears where wave peaks from multiple sources coincide; destructive (dark hollows) where peaks cancel troughs. Two coherent sources produce hyperbolic fringe curves — Young's 1801 double-slit pattern that demonstrated the wave nature of light. Phase offsets between sources *steer* the constructive interference in a chosen direction — the principle behind phased-array antennas. The simulation is one summed expression; no time stepping.

</Admonition>

**Common pitfalls to avoid**

- Forgetting the amplitude decay — every source contributes equally regardless of distance, looks artificial.
- Setting amplitude decay too aggressive — sources fade so fast that no interference is visible.
- Using `sin` instead of `cos` — works for the interference shape but shifts the phase convention.
- Comparing to moiré (6.4.1) — both use summed cosines, but moiré is the *visual* beating of two near-frequencies; interference is the *physical* superposition of distinct waves.
- Treating the static field as a moving wave — this is the *time-averaged* interference. For animation you would multiply by `cos(ωt)` and increment `t` per frame.
