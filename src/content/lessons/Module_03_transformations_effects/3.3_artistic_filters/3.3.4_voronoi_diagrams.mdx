## Overview <a id="overview"></a>

A **Voronoi diagram** partitions a plane into cells, one per seed point: every pixel belongs to the cell of whichever seed is closest. The boundaries between cells are equidistant from their two nearest seeds, and where three cells meet, the meeting point is equidistant from three seeds at once. Georges Voronoy formalised the construction in 1908; the same partition has since shown up in everything from crystallography and ecology to map graphics and procedural texturing [1, 2]. The NumPy version is a one-screenful broadcast: build the per-pixel distance to every seed, take the `argmin` along the seed axis, and you have the partition.

### Learning objectives

<ol class="obj-list">
  <li>Read a Voronoi diagram as a *nearest-seed-point* assignment over a 2D plane.</li>
  <li>Compute pixel-to-seed distances with a single broadcast and reduce them with `argmin` along the right axis.</li>
  <li>Use the resulting integer label map as an index into a colour palette.</li>
  <li>Switch metric — Euclidean → Manhattan / Chebyshev — and see the cell shapes change.</li>
</ol>

## Quick start — a 12-seed Voronoi <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image

SIZE = 400
NUM_SEEDS = 12
rng = np.random.default_rng(0)

# Random seeds in the plane
seeds = rng.integers(0, SIZE, size=(NUM_SEEDS, 2))   # shape (N, 2)

# Per-pixel distance to each seed, computed by broadcasting
y, x = np.indices((SIZE, SIZE))           # shape (SIZE, SIZE) each
dy = y[..., None] - seeds[:, 0]           # shape (SIZE, SIZE, N)
dx = x[..., None] - seeds[:, 1]
dist_sq = dy * dy + dx * dx               # squared Euclidean, no sqrt needed

# Index of the nearest seed for every pixel — the Voronoi label map
labels = np.argmin(dist_sq, axis=-1)      # shape (SIZE, SIZE)

# Colour palette (one entry per seed)
palette = rng.integers(40, 220, size=(NUM_SEEDS, 3), dtype=np.uint8)

# Look up the colour of each pixel's owner seed
image = palette[labels]
Image.fromarray(image).save('voronoi.png')
```
</CodeBlock>

<Admonition type="tip">
The whole construction is one broadcast plus one `argmin`. No loops over pixels; no loops over seeds. The shape gymnastics with `y[..., None]` and `seeds[:, 0]` are what set up the broadcast to a `(H, W, N)` distance tensor.
</Admonition>

<Admonition type="important">
The `[..., None]` adds a length-1 axis at the end of the array so it broadcasts against the seed axis. NumPy's broadcasting rules align trailing dimensions — `(H, W, 1)` broadcasts with `(N,)` to give `(H, W, N)`. Mismatch this and you get either a cryptic shape error or a silently wrong result.
</Admonition>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — The nearest-seed partition

Given seeds `p₁, ..., p_N` in the plane, the Voronoi cell of `pᵢ` is the set of points `q` such that `‖q − pᵢ‖ < ‖q − pⱼ‖` for every other seed `pⱼ`. In short: each cell collects the points for which one specific seed is the closest. The cell boundaries — points equidistant from two seeds — are straight-line *perpendicular bisectors* of the seed-to-seed segments. Three-way junctions (where three cells meet) are circumcenters of seed triples. The whole pattern is *deterministic* given the seeds; randomness only enters through how we picked the seeds [1].

<Admonition type="dyk" title="Technical note · Voronoy and Dirichlet">
The construction is sometimes called a Dirichlet tessellation in mathematics; Voronoy's 1908 paper studied higher-dimensional generalisations of the same partition. The English-language convention "Voronoi" comes from the French transliteration of his Russian name — both spellings refer to the same Georges/Yury Voronoy [3].
</Admonition>

### Concept 2 — The broadcast distance trick

Computing nearest-seed-per-pixel naively would be `O(H × W × N)` Python loops — slow at any interesting resolution. NumPy broadcasting does the same thing in one C-vectorised expression:

```python
y, x = np.indices((H, W))            # (H, W) each
dy = y[..., None] - seeds[:, 0]      # (H, W, N)
dx = x[..., None] - seeds[:, 1]
dist_sq = dy * dy + dx * dx          # (H, W, N) — distance from every pixel to every seed
```

The `dist_sq` tensor has one slice per seed; `dist_sq[..., i]` is a full squared-distance map for seed `i`. Reducing along the seed axis with `argmin` collapses the tensor to the cell label map:

```python
labels = np.argmin(dist_sq, axis=-1)   # (H, W) int — owner seed for every pixel
```

Skipping the square root is the standard trick — `argmin` of squared distances is the same as `argmin` of distances, because `sqrt` is monotonic.

### Concept 3 — Label map → colour map

Once `labels` exists, every pixel carries a seed index. Looking up colours by index is one indexing call:

```python
palette = rng.integers(40, 220, size=(N, 3), dtype=np.uint8)   # (N, 3) RGB
image   = palette[labels]                                       # (H, W, 3)
```

This is the *same* index-into-palette pattern used by GIF rendering, by `matplotlib.cm`, and by every game engine since the SNES — store an integer index per pixel, look up the colour separately. Swapping the palette swaps the whole picture without re-running the Voronoi computation.

<Admonition type="important">
For an outlined Voronoi (cell borders drawn), you can compute the border mask from the label map: a pixel is on a border if any of its 4 neighbours has a different label. `borders = labels != np.roll(labels, 1, axis=0)` (then OR with shifts along the other axes) is one cheap way; for larger cells you can pad with `np.diff(labels, axis=0).any()` and friends.
</Admonition>

## Exercises <a id="exercises"></a>

Three exercises in **Execute → Modify → Create** order: run the 12-seed Voronoi, swap distance metric and seed count, then add outlines.

<Exercise n={1} kicker="EXECUTE" title="Run the quick-start Voronoi">

Run `voronoi.py` from the downloads. Inspect the output.

**Reflection questions**

- Why are the cell boundaries straight lines and not curves?
- Some cells touch the edge of the canvas. Why are *those* cells the largest?
- What would happen if two seeds were placed at the same point?

<Dropdown summary="Answers">

**Straight boundaries** — the set of points equidistant from two fixed points is the perpendicular bisector of the segment joining them, which is a straight line. The Voronoi boundary is exactly that bisector, restricted to the region where the two seeds are *jointly* the two closest.

**Edge cells are large** — a Voronoi cell extends until it meets the next-closest seed. Near the edge there are no seeds *outside* the canvas to bound the cell, so it stretches to the canvas border. Cells away from any edge are clamped on all sides by neighbouring seeds.

**Two coincident seeds** — the points equidistant from both are *every* point in the plane (the two seeds *are* the same). Both labels are equally valid; `np.argmin` returns the *first* one it sees, so the second seed's cell becomes empty and you see one fewer cell than you placed seeds.

</Dropdown>

</Exercise>

<Exercise n={2} kicker="MODIFY" title="Three Voronoi variations">

Edit `voronoi.py` to produce these pictures.

**Goals**

1. **30 seeds** — increase `NUM_SEEDS`; the cells become finer and the pattern busier.
2. **Manhattan metric** — replace the squared Euclidean with `|dx| + |dy|`. The cells become rectilinear with horizontal, vertical, and 45° boundaries.
3. **Chebyshev metric** — `max(|dx|, |dy|)`. The cells become *axis-aligned rectangles*, called the L∞ Voronoi.

<Dropdown summary="Goal 1 — what to expect">

```python
NUM_SEEDS = 30
```

A finer mosaic. Each cell is smaller; boundaries are denser; the colour palette spreads over more cells.

</Dropdown>

<Dropdown summary="Goal 2 — what to expect">

```python
dist = np.abs(dy) + np.abs(dx)           # Manhattan distance
labels = np.argmin(dist, axis=-1)
```

Boundaries that were diagonal lines (perpendicular bisectors in Euclidean) become "staircase" boundaries — only horizontal, vertical, and 45° segments. The cells look like a city map of right-angled streets.

</Dropdown>

<Dropdown summary="Goal 3 — what to expect">

```python
dist = np.maximum(np.abs(dy), np.abs(dx))   # Chebyshev distance
labels = np.argmin(dist, axis=-1)
```

Cells become *rectangles* aligned with the axes. The Chebyshev Voronoi is sometimes called the "king's move" partition because a chess king reaches all squares within Chebyshev distance equal to the move count.

</Dropdown>

</Exercise>

<Dropdown summary="Hint 1 — neighbour comparison">

Compare each pixel's label with its four neighbours using `np.roll` or padded slicing:

```python
up    = labels != np.pad(labels[:-1], ((1, 0), (0, 0)), mode='edge')
down  = labels != np.pad(labels[1:],  ((0, 1), (0, 0)), mode='edge')
left  = labels != np.pad(labels[:, :-1], ((0, 0), (1, 0)), mode='edge')

borders = up | down | left | right
```

Each comparison gives a `(H, W)` boolean. OR them together to get a 1-pixel-wide ring on every cell boundary.

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image

SIZE = 400
NUM_SEEDS = 18
rng = np.random.default_rng(42)

seeds = rng.integers(0, SIZE, size=(NUM_SEEDS, 2))
y, x = np.indices((SIZE, SIZE))
dy = y[..., None] - seeds[:, 0]
dx = x[..., None] - seeds[:, 1]
dist_sq = dy * dy + dx * dx
labels = np.argmin(dist_sq, axis=-1)

palette = rng.integers(40, 220, size=(NUM_SEEDS, 3), dtype=np.uint8)
image = palette[labels]

up    = labels != np.pad(labels[:-1], ((1, 0), (0, 0)), mode='edge')
down  = labels != np.pad(labels[1:],  ((0, 1), (0, 0)), mode='edge')
left  = labels != np.pad(labels[:, :-1], ((0, 0), (1, 0)), mode='edge')
right = labels != np.pad(labels[:, 1:],  ((0, 0), (0, 1)), mode='edge')
borders = up | down | left | right

image[borders] = [0, 0, 0]
Image.fromarray(image).save('voronoi_outlined.png')
```
</CodeBlock>

**How it works:**

- Four `np.pad` calls produce neighbour-shifted copies of the label map. Each comparison flags pixels that differ from a neighbour in one direction.
- ORing the four boolean maps gives the union of all such pixels — the cell boundaries.
- `image[borders] = [0, 0, 0]` paints the ring black; the cell interiors retain their palette colour.

</Dropdown>

#### Make it your own

- Place the seeds on a grid (`np.mgrid`-derived) instead of random. The Voronoi is a regular hexagonal or square tiling.
- Colour each cell by its *seed's position* — `palette[i] = [seeds[i, 0], seeds[i, 1], 128]` — and the picture becomes a graceful spatial gradient.
- Use a 3D distance computation (`dy*dy + dx*dx + something_z`) to get a Voronoi-noise pattern where the "z" coordinate is animated over time.

</Exercise>

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

A Voronoi diagram is the nearest-seed partition of a plane: every pixel belongs to the cell of its closest seed, the cell boundaries are perpendicular bisectors of seed-to-seed segments, and three-way junctions are circumcenters of seed triples. NumPy implements it as a single broadcast (`y[..., None] - seeds[:, 0]`) producing a `(H, W, N)` distance tensor, followed by `argmin(axis=-1)` to collapse the tensor into a label map. Once the label map exists, colours are a palette lookup, outlines are a 4-neighbour difference, and the same construction generalises to any distance metric — swap Euclidean for Manhattan and the cells become rectilinear; swap for Chebyshev and they become rectangles. The trick is everywhere in computational geometry, procedural art, and crystallography.

</Admonition>

**Common pitfalls to avoid**

- Forgetting `y[..., None]` — without the extra axis, NumPy can't broadcast pixel grids against the seed array.
- Taking `sqrt` before `argmin` — slower, and the result is identical because `sqrt` is monotonic.
- Indexing into the palette with the *wrong* dtype — `labels` must be integer; floats raise.
- Coincident seeds — `argmin` picks the first match, so duplicate seeds silently disappear from the partition.
- A border mask built only on the right and down comparisons — produces a one-sided border. Always combine all four directions for symmetric outlines.
