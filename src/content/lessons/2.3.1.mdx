## Overview <a id="overview"></a>

A Lissajous curve is what you get when you let two perpendicular sinusoids run at different frequencies and trace the joint position over time:

$$x(t) = A \sin(at + \delta), \quad y(t) = B \sin(bt).$$

Jules Lissajous coupled two tuning forks to a mirror in 1857 to show acoustic frequency ratios optically — the same geometry that runs across every oscilloscope screen today [1]. The visual is decided by three numbers: the frequency ratio `a:b` (the basic shape), the phase shift `δ` (the rotation/tilt), and the rationality of `a/b` (whether the curve closes or fills the rectangle).

### Learning objectives

<ol class="obj-list">
  <li>Parameterise a 2D curve with two independent sinusoids in x and y.</li>
  <li>Predict the lobe count of a Lissajous figure from its frequency ratio `a:b`.</li>
  <li>Tune the phase shift δ to twist the figure between aligned, opened, and tilted variants.</li>
  <li>Colour a parametric curve by its `t`-progress to expose how it sweeps through the closed shape.</li>
</ol>

## Quick start — a 3:4 Lissajous figure <a id="quick-start"></a>

<CodeBlock lang="python" file="quick_start.py">
```python
import numpy as np
from PIL import Image

CANVAS_SIZE = 512
canvas = np.zeros((CANVAS_SIZE, CANVAS_SIZE), dtype=np.uint8)

amplitude = 220
a, b = 3, 4
delta = np.pi / 2

t = np.linspace(0, 2 * np.pi, 4000)
xs = CANVAS_SIZE / 2 + amplitude * np.sin(a * t + delta)
ys = CANVAS_SIZE / 2 + amplitude * np.sin(b * t)

xi = np.round(xs).astype(int)
yi = np.round(ys).astype(int)
inside = (xi >= 0) & (xi < CANVAS_SIZE) & (yi >= 0) & (yi < CANVAS_SIZE)
canvas[yi[inside], xi[inside]] = 255

Image.fromarray(canvas, mode='L').save('simple_lissajous.png')
```
</CodeBlock>

## Core concepts <a id="core-concepts"></a>

### Concept 1 — Two perpendicular oscillators

A Lissajous curve is the locus of the joint output of two independent harmonic oscillators driving the x- and y-axes:

$$x(t) = A \sin(a t + \delta), \qquad y(t) = B \sin(b t).$$

`A` and `B` set the bounding rectangle (width × height). `a` and `b` are the angular frequencies — how many full sinusoidal cycles each axis completes per unit of `t`. `δ` is the phase shift between the two oscillators. `t` is the time parameter; you sample it densely with `np.linspace`.

The hardware origin of this picture is mechanical [1]: Lissajous lit a beam, bounced it off a mirror on one tuning fork, then a mirror on a perpendicular tuning fork, and projected the result on a wall. Different tuning forks gave different ratios, and the resulting curve was the **audible frequency ratio rendered visible**.

<CodeBlock lang="python" file="oscillators_demo.py">
```python
t = np.linspace(0, 2 * np.pi, 4000)
xs = np.sin(3 * t + np.pi / 2)   # x runs three cycles
ys = np.sin(4 * t)                # y runs four cycles
# (xs, ys) traces the 3:4 Lissajous figure
```
</CodeBlock>

### Concept 2 — Frequency ratio decides the lobe count

The ratio `a:b` is the figure's "name". The conventional way to read it: with the standard `δ = π/2` phase shift, the curve has `b` lobes touching the top and bottom edges and `a` lobes touching the left and right edges. The classic `1:2` figure is the parabolic figure-eight; `2:3` is the symmetric tri-cusp; `3:4` is the lattice you saw above.

Equally important: the curve **closes** only when `a/b` is rational. If `a/b = p/q` in lowest terms, the figure repeats every $2\pi q$ in `t`. If `a/b` is irrational (say, `a = √2, b = 1`), the curve never closes — it eventually fills the entire bounding rectangle densely [2]. Numerically you can only sample a finite stretch of `t`, but the visual difference is real: rational ratios produce crisp closed lines, irrational ratios produce a haze that fills the rectangle.

<Admonition type="dyk" title="Technical note · the oscilloscope X-Y mode">
Every oscilloscope has an X-Y mode where the horizontal time-base is replaced by a second voltage input. Feed two sine generators into it and the screen shows a Lissajous figure in real time — the easiest way to measure the frequency ratio of two unknown signals, since the lobe count is the ratio [3].
</Admonition>

### Concept 3 — Phase shift δ as the twist knob

With the frequency ratio fixed, the phase shift `δ` between the two oscillators rotates and reshapes the figure. The qualitative effect for `a = b = 1`:

- `δ = 0` — the curve degenerates to a straight diagonal line (x and y are in phase).
- `δ = π/2` — a clean circle (90° phase, the standard "Lissajous figure" pose).
- `δ = π` — the diagonal line, mirrored.
- in between — ellipses with varying eccentricity.

For higher frequencies the picture is similar but more complex — `δ` opens and closes the lobes in different combinations, producing a continuous family of related figures. Mathematically, changing `δ` is equivalent to a 2D rotation of the curve's traced path, although the parametric form is the cleanest description [2].

<CodeBlock lang="python" file="phase_demo.py">
```python
for delta in [0, np.pi / 6, np.pi / 4, np.pi / 2]:
    xs = np.sin(t + delta)
    ys = np.sin(t)
    # plot — degenerates from line to ellipse to circle
```
</CodeBlock>

**Reflection questions**

- How many horizontal and vertical lobes does the figure have, and how do those numbers relate to `a` and `b`?
- What happens to the picture if you increase `num_points` from 4000 to 40000?
- Try `a = b = 1` and `δ = 0`. What do you get and why?

<Dropdown summary="Answers">

**Lobe counts** — 3 lobes touch the top and bottom, 4 lobes touch the left and right. With the standard `δ = π/2`, the figure has `b` lobes on the horizontal extrema and `a` on the vertical extrema. The 3:4 figure earns its name from this lobe count.

**Increasing num_points** — the line just gets smoother. Since the same curve is being traced more densely, no new structure appears. You will notice this most where the curve crosses itself — those crossings get cleaner.

**`a = b = 1, δ = 0`** — `x(t) = sin(t)`, `y(t) = sin(t)`. Same value on both axes at every `t`, so the points all lie on `y = x` — a 45° diagonal line. Changing `δ` to `π/2` would give `y = cos(t)`, and the curve closes into a unit circle.

</Dropdown>

</Exercise>

<Dropdown summary="Hint 1 — six-segment hue mapping">

```python
def hue_to_rgb(hue):
    h6 = hue * 6
    c = np.ones_like(h6); z = np.zeros_like(h6)
    x = 1 - np.abs((h6 % 2) - 1)
    seg = h6.astype(int) % 6
    r = np.choose(seg, [c, x, z, z, x, c])
    g = np.choose(seg, [x, c, c, x, z, z])
    b = np.choose(seg, [z, z, x, c, c, x])
    return (np.stack([r, g, b], axis=-1) * 255).astype(np.uint8)
```

This is the same HSV-wheel helper used in 2.2.3 for vector fields — the colour wheel and the unit circle of phases are the same shape, so the same function works for both.

<Dropdown summary="Complete solution">

<CodeBlock lang="python" file="exercise3_solution.py">
```python
import numpy as np
from PIL import Image

def hue_to_rgb(hue):
    h6 = hue * 6
    c = np.ones_like(h6); z = np.zeros_like(h6)
    x = 1 - np.abs((h6 % 2) - 1)
    seg = h6.astype(int) % 6
    r = np.choose(seg, [c, x, z, z, x, c])
    g = np.choose(seg, [x, c, c, x, z, z])
    b = np.choose(seg, [z, z, x, c, c, x])
    return (np.stack([r, g, b], axis=-1) * 255).astype(np.uint8)

CANVAS_SIZE = 512
canvas = np.zeros((CANVAS_SIZE, CANVAS_SIZE, 3), dtype=np.uint8)

amplitude = 220
a, b = 5, 6
delta = np.pi / 2
num_points = 6000

t = np.linspace(0, 2 * np.pi, num_points)
xs = CANVAS_SIZE / 2 + amplitude * np.sin(a * t + delta)
ys = CANVAS_SIZE / 2 + amplitude * np.sin(b * t)

progress = np.linspace(0, 1, num_points)
colors = hue_to_rgb(progress)

xi = np.round(xs).astype(int)
yi = np.round(ys).astype(int)
inside = (xi >= 0) & (xi < CANVAS_SIZE) & (yi >= 0) & (yi < CANVAS_SIZE)

canvas[yi[inside], xi[inside]] = colors[inside]

Image.fromarray(canvas, mode='RGB').save('colored_lissajous.png')
```
</CodeBlock>

**How it works:**

- `progress = np.linspace(0, 1, num_points)` numbers each sample point from 0 to 1.
- `hue_to_rgb` maps progress to a six-segment colour wheel — red at the start, green in the middle, magenta at the end.
- Boolean masking with `inside` keeps coordinates and colours aligned when some points fall outside the canvas.
- The advanced-indexed assignment `canvas[yi[inside], xi[inside]] = colors[inside]` writes per-point colours in one vectorised step.

</Dropdown>

## Summary <a id="summary"></a>

<Admonition title="Key takeaways">

A Lissajous curve is the parametric pair `(sin(at + δ), sin(bt))`. The ratio `a:b` decides the basic lobe pattern, `δ` rotates and tilts it, and the rationality of `a/b` decides whether the curve closes or fills the rectangle. Same scaffolding as the spiral lesson — `linspace` for the parameter, two trig functions for coordinates, line drawing or per-point indexing for the render. Add a `progress` array and a hue-mapping helper and you have a coloured ribbon that shows the traversal order. The next lesson — rose curves — uses the same parametric idea with polar coordinates instead of two perpendicular sinusoids.

</Admonition>

**Common pitfalls to avoid**

- Too few sample points — large frequency ratios need denser `t` to look smooth. Bump `num_points` until the line has no visible gaps.
- Using `degrees` instead of `radians` for `a*t + δ` — `np.sin` expects radians.
- Forgetting to centre `xs` and `ys` on the canvas — the bounding rectangle ends up at `(-A, +A)` instead of around `CANVAS_SIZE / 2`.
- Expecting `a = b` to give an interesting figure — it does not, unless `δ != 0`. With `δ = 0` and `a = b`, the curve collapses to a diagonal line.
