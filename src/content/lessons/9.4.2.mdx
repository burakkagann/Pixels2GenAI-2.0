## Big question <a id="big-question"></a>

*What do the intermediate feature maps of a CNN look like, and what artistic use can we put them to?* Inside every trained convolutional network, each layer produces dozens or hundreds of *feature maps* — 2D grids of activations, one per learned filter. Each map highlights a different aspect of the input: one for horizontal edges, one for diagonals, one for textures, one for round objects. Visualising these maps is the standard interpretability tool [1]; arranging them as an artistic grid is a creative repurposing. This lesson uses hand-crafted oriented filters to produce the same kind of feature-map grid a CNN would generate internally.

### Learning objectives

<ol class="obj-list">
  <li>Generate a bank of oriented filter kernels — Gabor-like — spanning a set of angles.</li>
  <li>Apply each filter to the same input image and store the responses.</li>
  <li>Tile the responses into a grid as a single composite output.</li>
  <li>Recognise that this is exactly what the first convolutional layer of a CNN does.</li>
</ol>

## Part 1 — Oriented filter bank <a id="part-1"></a>

Gabor filters are sinusoidal patches modulated by a Gaussian envelope. They look like local oriented stripes and detect edges and textures at specific angles:

```python
def gabor_kernel(angle_deg, size=7, freq=3, sigma=0.4):
    u = np.linspace(-1, 1, size)
    gx, gy = np.meshgrid(u, u)
    a = np.deg2rad(angle_deg)
    rot = gx * np.cos(a) + gy * np.sin(a)
    k = np.cos(rot * freq) * np.exp(-(gx**2 + gy**2) / sigma)
    return k / np.abs(k).sum()
```

A bank of six kernels at 0°, 30°, 60°, 90°, 120°, and 150° covers all orientations. Each one fires strongest on edges aligned with its preferred direction.

## Part 2 — Apply and tile <a id="part-2"></a>

For each kernel, convolve with the input and store the response:

```python
def feature_bank(image, kernels):
    return [convolve(image, k) for k in kernels]
```

Tile the responses into a grid using the `hstack`/`vstack` pattern from 3.3.2:

```python
gap = np.zeros((H, 6))
gap_v = np.zeros((6, 3 * W + 2 * 6))
row1 = np.hstack([maps[0], gap, maps[1], gap, maps[2]])
row2 = np.hstack([maps[3], gap, maps[4], gap, maps[5]])
grid = np.vstack([row1, gap_v, row2])
```

## Part 3 — Why this is what CNNs do <a id="part-3"></a>

The first convolutional layer of any image-trained CNN — AlexNet, VGG, ResNet — has filters that *look like* this Gabor bank. Trained on millions of natural images, the network rediscovers the same oriented-edge detectors that 1980s computer-vision research designed by hand [2, 3].

The artistic use is that the feature-map grid *is the composition*. Six filters → six panels → one composite. Twelve filters → twelve panels. The grid is its own visual structure, and the per-panel content carries information about the input.

<Admonition type="dyk" title="Technical note · Hubel and Wiesel">
The biological inspiration for these filters predates computer vision. David Hubel and Torsten Wiesel won the 1981 Nobel Prize for showing that neurons in cat visual cortex have *orientation-selective* receptive fields — they fire most strongly for stimuli aligned with a particular angle [4]. CNN first-layer filters are direct artificial analogues of these biological orientation columns.
</Admonition>

## Synthesis project <a id="synthesis"></a>

<Exercise n={1} kicker="EXECUTE" title="Generate the 6-filter grid">

Run `feature_grid.py` from the downloads. It generates a synthetic input (concentric stripes), applies six oriented Gabor filters, and saves the 2×3 grid.

**Reflection questions**

- Which filter's response panel has the brightest pixels overall?
- Why are some panels nearly empty? (Hint: think about what edges the input image contains.)
- What would happen if you used a *photograph* as input instead of a synthetic pattern?

<Dropdown summary="Answers">

**Brightest** — depends on the input. For the concentric-stripe pattern, the panels for horizontal and vertical filters respond strongest at the cardinal points; diagonals at the four corners of each ring.

**Empty panels** — if the input has no edges at a particular angle, the filter for that angle has no input to respond to. Empty panels are *information*: they say the input lacks that orientation.

**Photograph** — natural images have edges at every angle, so all panels would have some content. The differences would be more subtle — texture, edge density, dominant orientation.

</Dropdown>

</Exercise>

<Exercise n={2} kicker="MODIFY" title="Sweep filter parameters">

Edit `feature_grid.py` for these variations.

**Goals**

1. **Twelve filters** instead of six, every 15° instead of every 30°.
2. **Multiple frequencies** — three filters at the same angle but with different `freq` values (`2`, `3`, `5`).
3. **Larger kernels** — bump kernel size from 7 to 15 for smoother, larger-scale features.

<Dropdown summary="Expected outcomes">

- **12 filters**: smoother orientation coverage. Adjacent panels look similar.
- **Multi-frequency**: detects edges at different *scales* — fine, medium, coarse. Larger features dominate the lower-frequency panels.
- **Larger kernels**: filters become more selective. The response is sharper at the right angles and weaker at off-angles. Tracks larger image structures.

</Dropdown>

</Exercise>

<Exercise n={3} kicker="CREATE" title="Apply a feature bank to a photograph">

Load a photograph (or use a Module 06 procedural texture as a stand-in), apply the six-filter bank, and render the response grid as an artistic composition.

<Dropdown summary="Approach">

```python
from PIL import Image
img = np.array(Image.open('panda.png').convert('L'), dtype=float) / 255.0
maps = [convolve(img, gabor_kernel(a)) for a in [0, 30, 60, 90, 120, 150]]
# Normalise each per-panel, then tile
grid = tile_panels([normalise(m) for m in maps], rows=2, cols=3)
Image.fromarray((grid * 255).astype(np.uint8), 'L').save('photo_features.png')
```

The artistic move is to *not* superimpose the filters — leaving the grid structure visible makes the work read as "diagnostic" and machinic, which is its own aesthetic.

</Dropdown>
