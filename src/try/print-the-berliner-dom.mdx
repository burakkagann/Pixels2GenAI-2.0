  <p>A pixel at brightness 10 is below 90 and below 150. Why did the blue ink never show when 150 came first?</p>

Python reads the `if`s from the top and stops at the first one that is `True`. So the narrow question (below 90) must come before the wide one (below 150).

<Hint>Brightness 10 is below 150, so the first `if` already answers for it. Which `if` should come first?</Hint>
<Hint>Check `light < 90` first, then `light < 150`. Keep the numbers.</Hint>
<Hint kind="solution">Move `if light < 90:` and its `return INK` above `if light < 150:`.</Hint>
