# Pixels2GenAI

**Pixels to generative AI — one continuous journey.**

A free, open curriculum that takes you from a single array element all the way
to building, training, and reasoning about modern generative AI. You learn by
making: every module ends in something you can *see* — a fractal, a flocking
swarm, a neural network, an image dreamed up by a generative model.

🌐 **Start learning: <https://pixels2genai.art>**

## What this is

Pixels2GenAI is an educational platform for learning generative art and AI from
the ground up. There's no magic and no black boxes: you begin with a single
number in an array, watch it become a pixel, then shapes, then motion, then a
model that can learn — until "generative AI" is no longer a buzzword but
something you've built with your own hands.

**Who it's for.** Semi-beginner to semi-experienced programmers who are curious
about creative AI and want to *understand* it, not just call an API — plus
teachers looking for a ready-made, adaptable path through the material. If you
can write a little Python and you're curious, you're the audience.

**What you'll make.** Each of the 15 modules produces a visual artifact you can
keep and share: geometric compositions, fractals, particle simulations,
procedural noise, animations, a neural network trained from scratch, and finally
images generated by GANs and diffusion models — culminating in a capstone
project that's entirely your own.

## Start learning — no setup required

If you're here to learn, you don't need to install anything:

> ### → Open **[pixels2genai.art](https://pixels2genai.art)** and click a lesson.

Every lesson is self-contained and runs in your browser-side reading flow: read
the idea, run the starter script, change a few parameters, then make it your own.
Pick a module that interests you, or start at the beginning and follow the thread.

## How it works

The curriculum is built on a simple, repeating learning loop:

- **Execute** — run a complete, working script and see the result immediately.
- **Modify** — change a few labelled parameters and watch what happens.
- **Create** — finish a partially-built script of your own, with hints and a
  full solution a click away.

It's **visual-first** (you see the outcome of every idea), built around
**immediate feedback**, and balanced at roughly **40% theory / 60% practice** —
enough concept to know *why*, enough making to know *how*. Each lesson is sized
for a single sitting and labelled with its level, duration, and the number of
new concepts it introduces.

## The journey — 3 cycles, 15 modules, 1 capstone

The climb is staged in three cycles. Each builds directly on the last, so the
distance from "a single pixel" to "a diffusion model" is covered one honest step
at a time.

| Cycle | Modules | What you build toward |
|-------|---------|-----------------------|
| **I · Foundations** | Foundations & Definitions · Pixel Fundamentals · Geometry & Mathematics · Transformations & Effects · Fractals & Recursion · Simulation & Emergent Behavior | Arrays become images, shapes, and living systems. |
| **II · Machine Learning** | Noise & Procedural Generation · Classical ML on Images · Animation & Time · Neural Networks · TouchDesigner · Interactive Systems | Images become data; data trains a model. |
| **III · Generative AI** | Generative AI Models · AI + TouchDesigner · Data as Material · **Capstone Project** | Models become creative collaborators — then you make your own piece. |

There are **193 hands-on exercises** across these modules. Lessons are published
module by module as they're polished — **72 are live as of June 2026**, with the
rest arriving steadily. The live site always shows what's ready right now; run
`npm run status` for the current count.

## For teachers

The curriculum is openly licensed (**CC-BY 4.0**) precisely so you can use and
adapt it:

- **Adopt a module or a cycle** as the spine of a course, workshop, or
  self-study group — the modules are sequential but you can enter at any cycle.
- **Reuse the scaffolding** — the *Execute → Modify → Create* structure and the
  per-lesson level / duration / cognitive-load labels make lessons easy to slot
  into a syllabus and to pace.
- **Adapt freely** — change examples, swap artifacts, or translate prose, as
  long as you keep attribution per CC-BY 4.0.

The design has been piloted in a workshop setting; see the
[workshops page](https://pixels2genai.art/workshops) and the research summary
below for what that looked like in practice.

## Free, open, and grounded in research

Pixels2GenAI is free and will stay that way:

- **Curriculum content** (lesson prose, figures, diagrams) — [CC-BY 4.0](LICENSE-CONTENT.md)
- **Code** (the site and tooling) — [MIT](LICENSE)

It's also the artifact of a **Master's thesis in creative computing**, built and
evaluated with Design-Based Research. That means the teaching choices aren't
guesses — they were tested with real learners and refined. You can read the
study, its findings, and its honest limitations on the
**[research page](https://pixels2genai.art/research)**.

## Run it locally / Contributing

You don't need any of this to learn — it's only for tinkering with the site
itself. The project is built with [Astro](https://astro.build) and needs
**Node 20**:

```bash
git clone https://github.com/burakkagann/Pixels2GenAI-2.0.git
cd Pixels2GenAI-2.0
npm install
npm run dev        # http://localhost:4321
```

Contributions are welcome — the most valuable one is **porting a lesson** from
the v1 archive into a polished v2 lesson. The full workflow, project layout,
scripts, quality bar, and PR checklist live in **[CONTRIBUTING.md](CONTRIBUTING.md)**.
